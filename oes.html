OES

Obsidian Effect Scripts: style, responsive behavior, and motion for ODL documents.

Tokens

Colors, spacing and motion values remain in OFS source.

Responsive

Media rules are generated through OES functions.

Effects

Transitions and keyframes form the effect layer.

theme.ofs
attach {oes}

vein theme() -> obsidian {
    forge s = oes.rule(":root", oes.var("accent", "#29e0bd"))
    s = s + oes.rule(".button", oes.prop("background", oes.use("accent")))
    s = s + oes.media("(max-width:700px)", ".grid{grid-template-columns:1fr}")
    s = s + oes.keyframes("enter", oes.frame("from", "opacity:0") + oes.frame("to", "opacity:1"))
    return s
}
