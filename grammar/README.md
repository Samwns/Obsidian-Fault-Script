# Obsidian Fault Script Grammar

TextMate-compatible syntax grammar for Obsidian Fault Script (`.ofs`).

- Scope: `source.ofs`
- Language: Obsidian Fault Script
- License: MIT
- Main project: https://github.com/Samwns/Obsidian-Fault-Script

This repository is the upstream grammar source intended for editor integrations
and a future GitHub Linguist contribution.

The `samples/` directory contains representative compiler, low-level, and
website-generation source rather than tutorial-only examples.
