Web UI

The component layer built on ODL, OES, and the native web server.

Components

Navigation, hero, button, panel, grid and card helpers.

Composition

Components are ordinary OFS functions returning obsidian.

Go Live

The extension starts only explicit OFS web programs.

webui.ofs
attach {webui}

core main() {
    forge body = webui.nav("OFS", webui.button("Docs", "#docs"))
    body = body + webui.grid(webui.card("ODL", "Documents") + webui.card("OES", "Effects"))
    webui.serve(8080, "OFS Web", body)
}
