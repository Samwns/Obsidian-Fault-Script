ODL

Obsidian Document Language: the structural document layer for OFS sites.

Documents

ODL generates browser documents from typed OFS functions.

Components

Any vein returning obsidian can be reused as a component.

Output

HTML is a generated artifact, not the authored language.

page.ofs
attach {odl}

vein page() -> obsidian {
    forge head = odl.css("site.css")
    forge body = odl.header("topbar", odl.h1("OFS Web"))
    body = body + odl.main("content", odl.section("docs", "band", odl.p("lead", "Built with ODL")))
    return odl.document("en", "OFS Web", "ODL document", head, body)
}
