Linguagem compilada hibrida

OFS compila, roda nativo e constroi a Web.

Uma linguagem self-hosted com LLVM, runtime nativo, ODL para documentos e OES para estilo, efeitos e movimento.

}

O que e a OFS

Uma linguagem para aprender, compilar e descer perto do sistema quando precisar.

Self-hosted

Lexer, parser, type checker e geracao LLVM vivem no compilador OFS.

Nativa

A saida e LLVM IR linkada com libofs_runtime.a para gerar executaveis.

Hibrida

Console, canvas/window nativo e sites via webserver/webui no mesmo ecossistema.

ODL + OES

ODL descreve documentos; OES define estilo, efeitos, responsividade e animacoes.

site.ofs
attach {odl}
attach {oes}
attach {webserver}

core main() {
    forge head = odl.css("site.css")
    forge body = odl.main("app", odl.h1("OFS Web"))
    webserver.serve_html_forever(8080, odl.document("pt", "OFS", "site", head, body))
}
