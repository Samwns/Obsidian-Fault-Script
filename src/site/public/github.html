Reconhecimento neste repositorio

PT

`.gitattributes` marca .ofs, .odl e .oes como fontes da linguagem para este projeto.

EN

`.gitattributes` marks .ofs, .odl, and .oes as language sources for this project.

Override local

*.ofs linguist-language=OFS.

ODL

*.odl linguist-language=ODL.

OES

*.oes linguist-language=OES.

GitHub Linguist

PT

Para reconhecimento global, a linguagem precisa de PR no Linguist com extensoes, escopos, cor, exemplos publicos e gramatica.

EN

For global recognition, the language needs a Linguist PR with extensions, scopes, color, public examples, and grammar.

languages.yml
OFS:
  type: programming
  color: "#2A0845"
  extensions:
    - ".ofs"
  tm_scope: source.ofs
ODL:
  type: markup
  extensions:
    - ".odl"
OES:
  type: markup
  extensions:
    - ".oes"

GitHub Pages

PT

GitHub Pages nao executa ODL/OES diretamente. O fluxo correto e gerar HTML/CSS em `docs/` e publicar o artefato.

EN

GitHub Pages does not execute ODL/OES directly. The correct flow is to generate HTML/CSS into `docs/` and publish the artifact.

A fonte oficial continua ODL/OES; HTML e CSS sao artefatos de hospedagem.
