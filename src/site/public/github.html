`.gitattributes` marca .ofs, .odl e .oes como fontes da linguagem para este projeto.

Override local

*.ofs linguist-language=OFS.

ODL

*.odl linguist-language=ODL.

OES

*.oes linguist-language=OES.

GitHub Linguist

PT

Para reconhecimento global, a linguagem precisa de PR no Linguist com extensoes, escopos, cor, exemplos publicos e gramatica.

languages.yml
OFS:
  type: programming
  color: "#2A0845"
  extensions:
    - ".ofs"
  tm_scope: source.ofs
ODL:
  type: markup
  extensions:
    - ".odl"
OES:
  type: markup
  extensions:
    - ".oes"

GitHub Pages

PT

GitHub Pages nao executa ODL/OES diretamente. O fluxo correto e gerar HTML/CSS em `docs/` e publicar o artefato.

A fonte oficial continua ODL/OES; HTML e CSS sao artefatos de hospedagem.
