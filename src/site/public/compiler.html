O compilador le o fonte, tokeniza, monta AST, valida semantica, gera LLVM IR e linka com runtime.

pipeline
source.ofs -> tokens -> AST -> semantic model -> LLVM IR -> native executable

Self-hosted

PT

O compilador principal fica em `ofs/ofscc`. Isso permite evoluir a linguagem usando a propria linguagem.

O bootstrap ainda preserva ferramentas de distribuicao para gerar instaladores limpos.

Artefatos

PT

`check` valida, `ir` mostra LLVM IR, `asm` gera assembly, `build` produz executavel.

commands
ofs check app.ofs
ofs ir app.ofs
ofs asm app.ofs -o app.s
ofs build app.ofs -o app
Gerado por ODL e OES em OFS.
