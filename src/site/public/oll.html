Modos visuais nativos

O OFS disponibiliza dois modos de UI nativa: imediato, com controle procedural do loop; e declarativo, com arquivo OLL que descreve a hierarquia de componentes.

Modo imediato

Renderização direta sobre buffers de pixel via `canvas`, `window` e `ui`. Controle total do loop de eventos.

Modo declarativo (OLL)

Árvore hierárquica de componentes definida em `.oll`. Taxa de quadros gerida pelo runtime.

OLL — Obsidian Layout Language

Arquivo `.oll` descreve a árvore de interface. O runtime interpreta e renderiza em janela X11 ou Win32 com taxa de quadros estável.

painel.oll
window "Painel" {
    width: 640
    height: 480
    bg_color: #1e1e2e
    padding: 24

    column {
        gap: 16
        header "Monitor" { fg_color: #cba6f7 }
        card {
            bg_color: #313244
            border_color: #45475a
            padding: 16
            row {
                label "CPU" { fg_color: #89b4fa }
                badge "45%" { fg_color: #a6e3a1 }
            }
            progress { value: 45 bg_color: #45475a fg_color: #a6e3a1 }
        }
        row {
            gap: 12
            button "Atualizar" { bg_color: #89b4fa fg_color: #11111b on_click: "refresh" }
            button "Fechar" { bg_color: #f38ba8 fg_color: #11111b on_click: "close" }
        }
    }
}

Execução

Use `ofs-ui` para abrir a janela interativa ou `ofs ui ... -o preview.ppm` para exportar um raster estático.

run
ofs-ui arquivo.oll

ofs ui arquivo.oll -o preview.ppm

Recursos suportados

Conjunto de nós, estilos e capacidades disponíveis no runtime OLL atual.

window, column, row

Nós de layout: janela raiz, empilhamento vertical e horizontal.

card, header, badge

Contenedor com borda, título de seção e etiqueta de valor.

button, label, input

Controles interativos com estado: idle, hover, active, disabled.

progress, checkbox

Barra de progresso e caixa de seleção com valor numérico.

Gerado por ODL e OES em OFS.
