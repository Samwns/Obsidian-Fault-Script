Stack web OFS

A stack separa logica OFS, documento ODL, efeito OES, servidor web e artefato gerado. ODL/OES sao fontes versionadas; HTML/CSS/JS sao targets de navegador.

1. ODL
Declare estrutura de documento em OFS.
2. OES
Gere tokens, regras e animacao.
3. Webserver
Sirva a saida gerada localmente.
4. Pages
Publique os artefatos gerados.
odl.ofs
attach {odl}
attach {oes}

vein page() -> obsidian {
    return odl.document("pt", "Site", "feito em OFS", "", odl.h1("OFS Web"))
}

Target web

Browsers aceitam HTML/CSS/JS. OFS gera esses arquivos para GitHub Pages, CDN e servidores comuns sem transformar os artefatos em fonte oficial.

ODL/OES tambem podem ser servidos como fonte para ferramentas, mas quem executa no navegador e o artefato gerado.

Backend separado

`webserver.ofs` e backend nativo: processo, socket, MIME, resposta HTTP e dados. ODL/OES nao devem carregar regra de backend dentro do documento; eles descrevem documento e visual.

Fonte

.ofs para processo e dados.

Documento

.odl para estrutura e componentes.

Efeito

.oes para tokens, layout e motion.

Interoperabilidade

ODL permite componentes, scripts modulares, Markdown e HTML bruto explicito. OES organiza tokens e efeitos e aceita propriedades do target quando ainda nao existe alias OES.

Gerado por ODL e OES em OFS.
