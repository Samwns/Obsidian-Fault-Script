A stack web da OFS

A arquitetura separa lógica nativa em OFS, estrutura em ODL, estilos em OES e servidor HTTP em `webserver.ofs`.

1. ODL
Declare estrutura de documento em OFS.
2. OES
Gere tokens, regras e animação.
3. Webserver
Sirva a saída gerada localmente.
4. Pages
Publique os artefatos gerados.
odl.ofs
attach {odl}
attach {oes}

vein page() -> obsidian {
    return odl.document("pt", "Site", "feito em OFS", "", odl.h1("OFS Web"))
}

Compilação para navegadores

Navegadores executam HTML, CSS e JavaScript padrão. O compilador traduz as fontes ODL e OES para esses formatos.

Fontes ODL e OES podem ser servidos para ferramentas de desenvolvimento enquanto navegadores processam os artefatos compilados.

Backend desacoplado

O módulo `webserver.ofs` executa como processo nativo, gerenciando requisições, cabeçalhos e fluxos de dados sem misturar lógica de negócio na marcação.

Lógica

.ofs para processos e dados.

Documento

.odl para estrutura semântica.

Estilos

.oes para tokens e movimento.

Interoperabilidade web

ODL oferece suporte integrado a Markdown, scripts modulares e marcação bruta quando necessária para migrações.
