ODL model

ODL is the OFS document language. It generates standard HTML for browsers, GitHub Pages, and static hosts.

Native syntax

ODL uses words such as `page`, `skin`, `flow`, `deck`, `stage`, `band`, `tile`, `mark`, `raw`, `wire`, `spark`, `pulse`, and `server`.

page.odl
page "OFS Web" "en"
skin "theme.css"
flow
  deck.topbar
    title1 "OFS Web"
    link.button "Documentation" "#docs"
  stage#content
    band.docs
      mark "## Native documents\nWrite **ODL**, generate HTML."
  spark "app.js"

Interop

`mark` accepts Markdown, `raw` accepts HTML, `spark` imports JS modules, `pulse` injects inline JS, and `server` can preserve PHP template blocks.

The source remains ODL. HTML is a generated hosting artifact.
