Core modules

EN

Core modules cover math, text, terminal input/output, and terminal presentation.

math.ofs

Implements square, cube, range sums, prime checks, digit counting, digit sums, number reversal, and numeric palindrome checks.

string.ofs

Wraps runtime text operations and provides repetition, first-character checks, and empty-string checks.

io.ofs

Provides prompt, separator, and header helpers for terminal programs.

terminal_colors.ofs

Defines ANSI colors and colored terminal output helpers.

core.ofs
attach {math}
attach {string}
attach {io}

core main() {
    print_header("Demo")
    echo(square(9))
    echo(repeat_str("OFS", 2))
}

Web modules

EN

The web stack ships with the standard library: ODL owns documents, OES owns effects, webserver owns HTTP, and webui provides components.

odl.ofs

Builds complete documents and semantic HTML nodes from typed OFS functions.

oes.ofs

Builds properties, rules, media queries, layers, variables, transitions, and keyframes.

webserver.ofs

Defines HTTP constants, response builders, MIME detection, JSON fragments, logging, and native serving loops.

webui.ofs

Provides themes and ready-made nav, hero, button, panel, grid, card, stack, page, and serve helpers.

Native visual modules

EN

Canvas, window, and UI target local native interfaces rather than browsers. They remain experimental and platform-dependent.

canvas.ofs

Experimental native 2D drawing API.

window.ofs

Native window lifecycle helpers.

ui.ofs

Immediate-mode UI measurements, text, boxes, and basic controls.

ofshtml.ofs

Legacy HTML helpers kept for migration to ODL.

System and FFI modules

EN

Bedrock, memory modes, and rift are explicit advanced layers for code that must move below the normal safe language surface.

bedrock.ofs

Low-level regions and pointer-oriented primitives.

bedrock_packet.ofs

Experimental packet structures for binary and protocol work.

memory_modes.ofs

Experiments around explicit memory modes.

rift.ofs

Experimental C ABI and FFI surface.

Importing

EN
