Commands and environment variables of the OFS compiler.

CLI commands

`ofs app.ofs` is the same as `ofs run app.ofs`.

ComandoPurpose
run app.ofsRuns interpreted; with --native builds a temporary binary first.
build app.ofsCompiles to a native executable (-o output).
check app.ofsType-checks without emitting code.
test app.ofsRuns the file tests (assay).
twin app.ofsRuns interpreted and native, comparing outputs.
polish app.ofsStyle and pattern checks.
language [en|pt|es]Shows or changes the CLI language.
ir / asm / tokens / astCompiler debug artifacts.
ui app.ollRenders a native OLL layout (-o output.ppm).
cleanCleans temporary build artifacts.
versionPrints the compiler version.
updateUpdates to the latest release.
