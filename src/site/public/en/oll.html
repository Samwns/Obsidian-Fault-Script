Native visual modes

OFS provides two native UI modes: immediate, with procedural event loop control; and declarative, with an OLL file describing the component hierarchy.

Immediate mode

Procedural rendering onto pixel buffers via `canvas`, `window`, and `ui`. Full event loop control.

Declarative mode (OLL)

Component tree defined in `.oll`. Frame timing managed by the runtime.

OLL — Obsidian Layout Language

An `.oll` file describes the interface tree. The runtime interprets and renders it in an X11 or Win32 window at a stable frame rate.

panel.oll
window "Panel" {
    width: 640
    height: 480
    bg_color: #1e1e2e
    padding: 24

    column {
        gap: 16
        header "Monitor" { fg_color: #cba6f7 }
        card {
            bg_color: #313244
            border_color: #45475a
            padding: 16
            row {
                label "CPU" { fg_color: #89b4fa }
                badge "45%" { fg_color: #a6e3a1 }
            }
            progress { value: 45 bg_color: #45475a fg_color: #a6e3a1 }
        }
        row {
            gap: 12
            button "Refresh" { bg_color: #89b4fa fg_color: #11111b on_click: "refresh" }
            button "Close" { bg_color: #f38ba8 fg_color: #11111b on_click: "close" }
        }
    }
}

Running

Use `ofs-ui` to open the interactive window or `ofs ui ... -o preview.ppm` to export a static raster image.

run
ofs-ui app.oll

ofs ui app.oll -o preview.ppm

Supported capabilities

Nodes, styling tokens, and runtime capabilities available in the current OLL runtime.

window, column, row

Layout nodes: root window, vertical stack, horizontal stack.

card, header, badge

Container with border, section heading, and value label.

button, label, input

Interactive controls with states: idle, hover, active, disabled.

progress, checkbox

Progress bar and checkbox with numeric value.
