OFS: a compiled language, native runtime, and its own web DSLs.

Obsidian Fault Script ships a self-hosted compiler that emits LLVM IR, links a native runtime, and includes ODL/OES as source languages for websites.

Get startedDownloadsGitHub
example.ofs
attach {odl}
attach {oes}

vein page() -> obsidian {
    forge head = odl.css("site.css")
    forge body = odl.h1("OFS Web")
    return odl.document("pt", "OFS", "site oficial", head, body)
}

Technical components

The ecosystem separates compiler, runtime, standard library, web tooling, and packaging.

Self-hosted

The lexer, parser, type checker, and LLVM generation all live in the OFS compiler itself.

Native

The output is LLVM IR linked with the native OFS runtime, producing real executables.

Hybrid

Console, native canvas/window, and websites via webserver and webui in one ecosystem.

ODL + OES

ODL describes documents; OES defines style, effects, responsiveness, and motion.

site.ofs
attach {odl}
attach {oes}
attach {webserver}

core main() {
    forge head = odl.css("site.css")
    forge body = odl.main("app", odl.h1("OFS Web"))
    webserver.serve_html_forever(8080, odl.document("en", "OFS", "site", head, body))
}
