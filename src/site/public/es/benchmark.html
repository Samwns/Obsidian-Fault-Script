Metodología de las pruebas

El script `bash bench/run.sh` compila cada implementación (OFS con el compilador y el runtime del repositorio, C con `clang -O2`, Rust con `rustc -O`), ejecuta procesos reales, compara la salida con `bench/expected/` y guarda la mediana del tiempo de pared. Cada proceso corre con límite de memoria (`ulimit -v`) y de tiempo.

Cómo interpretar los datos

Los resultados dependen del hardware, el sistema operativo y la configuración de compilación. Las mediciones puntuales reflejan la carga probada, no afirmaciones universales de velocidad.

memoria: el proceso superó el límite de memoria y fue terminado. timeout: superó el límite de tiempo. fallo: terminó con error por otro motivo. La máquina, la fecha y las versiones aparecen sobre los gráficos.
