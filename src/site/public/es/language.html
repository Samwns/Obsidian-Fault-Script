Conceptos fundamentales de Obsidian Fault Script.

Que es OFS

OFS es un lenguaje compilado self-hosted. El compilador esta escrito en OFS, genera LLVM IR y enlaza un runtime nativo.

hola.ofs
vein sumar(a: stone, b: stone) -> stone {
    return a + b
}

core main() {
    echo(sumar(20, 2))
}

Elementos principales

`vein` declara funciones, `forge` crea variables, `core main()` es la entrada, `attach` importa bibliotecas y `monolith` define estructuras.

Compilacion

`check` valida, `run` compila y ejecuta, `build` crea un ejecutable, `ir` muestra LLVM IR y `asm` genera assembly.

terminal
ofs check app.ofs
ofs run app.ofs
ofs build app.ofs -o app
Generado por ODL y OES en OFS.
