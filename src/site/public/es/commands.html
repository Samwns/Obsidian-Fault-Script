Comandos CLI

`ofs app.ofs` equivale a `ofs run app.ofs`.

ComandoProposito
run app.ofsEjecuta interpretado; con --native compila un binario temporal.
build app.ofsCompila a un ejecutable nativo (-o salida).
check app.ofsVerificacion de tipos sin emitir codigo.
test app.ofsEjecuta las pruebas (assay) del archivo.
twin app.ofsEjecuta interpretado y nativo comparando salidas.
polish app.ofsVerifica estilo y patrones del codigo.
language [en|pt|es]Muestra o cambia el idioma de la CLI.
ir / asm / tokens / astArtefactos de depuracion del compilador.
ui app.ollRenderiza un layout OLL nativo (-o salida.ppm).
cleanLimpia artefactos temporales de build.
versionMuestra la version del compilador.
updateActualiza a la ultima release.
