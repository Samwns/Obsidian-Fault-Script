WebTheme

`WebTheme` concentra `bg`, `surface`, `text`, `muted`, `accent`, `border`, `radius` e `gap`. Alterar um tema muda o stylesheet gerado por uma unica funcao. `theme_light` e `theme_dark` fornecem valores iniciais, mas o programa pode preencher sua propria estrutura.

theme.ofs
forge theme = webui.theme_light()
theme.accent = "#a978ff"
theme.radius = 4

Referencia de componentes

Os componentes retornam `obsidian`, portanto podem ser concatenados, retornados por funcoes e guardados em variaveis. Eles nao mantem estado interno: a composicao ocorre durante a geracao da pagina.

FuncaoO que gera
theme_dark / theme_lightWebTheme com cor, superficie, texto, borda, raio e gap.
stylesheetBloco style completo baseado no tema.
pageDocumento HTML completo com viewport e tema.
navBarra de navegacao.
heroArea principal com titulo, subtitulo e acao.
buttonLink visual de comando.
panel / grid / card / stackContainers de composicao.
serveCria pagina e inicia servidor HTML.

Exemplo completo

O exemplo cria navegacao, hero, grid de cards e inicia o servidor. Cada parte pode ser movida para uma `vein` reutilizavel.

webui.ofs
attach {webui}

core main() {
    forge body = webui.nav("OFS", webui.button("Docs", "#docs"))
    body = body + webui.grid(webui.card("ODL", "Documents") + webui.card("OES", "Effects"))
    webui.serve(8080, "OFS Web", body)
}

Go Live e recarga

A extensao reconhece `attach {webui}` ou chamadas web explicitas, compila o programa e abre a URL local. Para `.odl`, ela tambem observa `.oes`, JavaScript e CSS vizinhos e injeta o cliente de recarga.
