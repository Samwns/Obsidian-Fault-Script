Comandos do compilador nativo

Comandos do CLI oficial para validação, inspeção e compilação de código OFS.

commands
ofs check app.ofs
ofs run app.ofs
ofs build app.ofs -o app
ofs odl page.odl -o index.html
ofs oes theme.oes -o theme.css
ofs translate legacy.html --to odl
ofs translate legacy.css --to oes

Comandos das linguagens web

`odl` e `oes` compilam documentos estruturais e estilos para a web padrão.

ComandoFinalidade
checkValida sintaxe e faz verificação estática de tipos.
runCompila temporariamente e executa o programa imediatamente.
buildCompila o arquivo-fonte para um executável nativo.
irEmite o código intermediário LLVM IR gerado.
asmEmite o código assembly nativo do arquivo.
odlCompila arquivos .odl para documentos HTML estruturados.
oesCompila arquivos .oes para folhas de estilo CSS.
translateTraduz arquivos HTML e CSS para sintaxe ODL e OES.

Tradutor de código web

Auxilia a conversão de arquivos legados HTML e CSS para a sintaxe ODL e OES.

O tradutor agiliza a migração inicial de componentes e páginas para a sintaxe da OFS.
Gerado por ODL e OES em OFS.
