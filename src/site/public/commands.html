Comandos da CLI

O binário `ofs` é o ponto de entrada: `ofs app.ofs` equivale a `ofs run app.ofs`.

commands
ofs app.ofs
ofs run app.ofs
ofs run app.ofs --native
ofs build app.ofs -o app
ofs check app.ofs
ofs ui app.oll -o app.ppm
ComandoFinalidade
runExecuta interpretado; com `--native` compila um binário temporário e roda.
buildCompila o arquivo-fonte para um executável nativo.
checkValida sintaxe e faz verificação estática de tipos.
testExecuta os testes (assay) do arquivo.
twinRoda interpretado e nativo, comparando as saídas.
polishVerifica estilo e padrões do código.
languageMostra ou altera o idioma da CLI (en, pt, es).
ir / asm / tokens / astArtefatos de depuração do compilador (LLVM IR, assembly, tokens, AST).
uiRenderiza um layout OLL nativo para um arquivo .ppm.
cleanLimpa artefatos temporários de build.
versionMostra a versão do compilador.
updateAtualiza para a última release.

Variáveis de ambiente

Opções de execução e localização de recursos reconhecidas pelo launcher.

VariávelFinalidade
OFS_LANGIdioma da CLI (en, pt, es).
OFS_PROGRESSFormato do reporter: fancy, plain ou json.
OFS_VERBOSELogs internos detalhados de link e build.
OFS_RUNTIMECaminho do objeto de runtime (magma.o) para linkagem.
OFS_STDLIB / OFS_STDLIB_PATHCaminho da biblioteca padrão.
Gerado por ODL e OES em OFS.
