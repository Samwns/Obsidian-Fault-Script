OES não é CSS

OES (Obsidian Effect Scripts) é uma linguagem declarativa para design systems, regras de estilo, contextos responsivos e animações. Ela é compilada para CSS padrão pelo ecossistema OFS.

OES mantém a semântica de tokens, camadas e animações consistente, atuando como o código-fonte visual primário.

Gemas e tokens de estilo

`gem` declara valores de estilo reutilizáveis. No código, `$nome` referencia o token com resolução de variáveis nativa.

tokens.oes
gem accent: Color = #a978ff
gem spacing: Size = 16px

paint .action
  fill: $accent
  space: $spacing

Regras e contextos responsivos

`paint` associa estilos a classes e elementos. `veil` encapsula regras para resoluções específicas, enquanto `guard` condiciona estilos a recursos do navegador.

theme.oes
gem accent: Color = #a978ff
gem surface: Color = #120d1f
paint .button
  fill: $accent
  curve: 8px
  transition: transform .2s ease
veil "(max-width: 700px)"
  paint .grid
    grid-cols: 1fr
pulse "enter"
  rise
    opacity: 0%
  rest
    opacity: 100%

Animações e quadros

`pulse` declara a animação, e `rise`, `rest` e `atNN` determinam os quadros da linha do tempo. As regras `paint` aplicam os pulsos através de propriedades de transição e animação.

motion.oes
pulse "enter"
  rise
    opacity: 0%
  at50
    opacity: 60%
  rest
    opacity: 100%

paint .panel
  animation: enter .24s ease

Edição visual segura

O modo Studio só é ativado em ambiente de desenvolvimento local (`localhost`) com o parâmetro `ofs-studio=1`. Ele permite ajustar propriedades visualmente sem sobrescrever código de produção.

As regras geradas no modo Studio podem ser inspecionadas e revisadas como código regular antes de serem commitadas.

Compilação para CSS

O compilador converte os arquivos `.oes` para folhas de estilo `.css` otimizadas, sem dependência de pré-processadores externos.
