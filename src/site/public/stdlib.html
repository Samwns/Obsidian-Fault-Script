Bibliotecas base

PT

Esses modulos sustentam programas pequenos e ferramentas do compilador.

math

Operacoes numericas e helpers matematicos.

string

Comprimento, recorte, comparacao e manipulacao de texto.

io

Entrada e saida basica.

fmt

Formatacao de valores para texto.

Sistema e runtime

PT

A familia bedrock/rift existe para experimentos controlados perto do runtime.

bedrock

Primitivos de integracao baixo nivel.

bedrock_packet

Estruturas de pacote para comunicacao experimental.

memory_modes

Experimentos controlados com memoria.

rift

Superficie experimental de runtime.

Web e UI

PT

A parte web e distribuida como stdlib, nao como ferramenta separada.

odl

Construcao de documentos HTML a partir de OFS.

oes

Geracao de estilo, responsividade e motion.

webui

Componentes e servidor de pagina.

webserver

Servidor HTTP nativo.

Como importar

PT

Use `attach {nome}` para bibliotecas instaladas ou `attach {F:caminho}` para arquivos locais.

attach
attach {math}
attach {string}
attach {odl}
attach {oes}
attach {webui}
