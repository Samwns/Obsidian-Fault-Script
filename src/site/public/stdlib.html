Módulos de núcleo

Os módulos fundamentais cobrem operações matemáticas, texto, entrada/saída de dados e terminal, disponíveis para qualquer executável OFS.

math.ofs

Funções numéricas em OFS puro: `square`, `cube`, `sum_range`, `is_prime`, `count_digits`, `sum_digits`, `reverse_number` e `is_palindrome_number`.

string.ofs

Utilitários sobre o runtime de strings: `repeat_str`, `starts_with_char` e `is_empty` para manipulação de texto.

io.ofs

Entrada e saída em terminal: `prompt`, `print_separator` e `print_header` para CLIs e ferramentas de console.

terminal_colors.ofs

Constantes ANSI e funções de formatação para saída de texto colorido no terminal.

base.ofs
attach {math}
attach {string}
attach {io}

core main() {
    print_header("Demo")
    echo(square(9))
    echo(repeat_str("OFS", 2))
}

Módulos para web

A biblioteca padrão inclui suporte nativo à stack web através de ODL, OES, webserver e webui sem dependências de pacotes externos.

odl.ofs

Construtor de documentos e nós semânticos para geração de HTML a partir de funções tipadas em OFS.

oes.ofs

Construtor de regras visuais, media queries, variáveis de estilo, keyframes e animações.

webserver.ofs

Servidor HTTP nativo com constantes de protocolo, montagem de respostas e detecção de tipos MIME.

webui.ofs

Biblioteca de temas e componentes visuais prontos para composição de páginas web completas.

site.ofs
attach {odl}
attach {oes}
attach {webserver}

core main() {
    forge page = odl.document("pt", "Site", "feito em OFS", odl.css("site.css"), odl.h1("OFS Web"))
    webserver.serve_html_forever(8080, page)
}

Interfaces nativas e desenho

Módulos dedicados à criação de janelas, renderização gráfica 2D direta e interfaces imediatas no sistema operacional.

canvas.ofs

API experimental de desenho 2D em buffer de pixels nativo (pontos, linhas, retângulos e formas).

window.ofs

Controle de ciclo de vida de janelas nativas e recepção de eventos de entrada.

ui.ofs

Primitivas de interface de modo imediato para texto, caixas e medições.

ofshtml.ofs

Helpers legados de HTML mantidos para compatibilidade com versões anteriores.

Sistema, baixo nível e FFI

Camadas avançadas para acesso direto à memória e integração com bibliotecas C através do sistema FFI.

bedrock.ofs

Primitivas de baixo nível para alocação direta de memória, regiões lineares e ponteiros manuais.

bedrock_packet.ofs

Estruturas de pacote binário para comunicação e protocolos de rede.

memory_modes.ofs

Definições e testes dos modos explícitos de gerenciamento de memória da linguagem.

rift.ofs

Superfície de interoperabilidade FFI com código nativo e bibliotecas compiladas em C.

Testes e módulos

Estruturas de convenção para organização de módulos, suítes de verificação e testes automatizados.

core.ofs

Módulo de convenções fundamentais e definições de tipos centrais.

test_lib.ofs

Estrutura auxiliar de asserções para suítes de testes automatizados da linguagem.

attach {F:...}

Sintaxe para importação direta de arquivos por caminho relativo ou absoluto.

attach {nome}

Sintaxe para importação de módulos instalados ou membros da biblioteca padrão.
