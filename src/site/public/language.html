O que e OFS

PT

OFS e uma linguagem compilada self-hosted. O compilador principal e escrito em OFS, gera LLVM IR e linka com um runtime nativo.

EN

OFS is a self-hosted compiled language. Its main compiler is written in OFS, emits LLVM IR, and links against a native runtime.

Sintaxe

PT

A linguagem usa funcoes `vein`, variaveis `forge`, retorno explicito e `core main()` como entrada.

EN

The language uses `vein` functions, `forge` bindings, explicit returns, and `core main()` as the entry point.

hello.ofs
// OFS source
vein add(a: stone, b: stone) -> stone {
    return a + b
}

core main() {
    forge result: stone = add(20, 2)
    echo(result)
}

Tipos

PT

Os tipos basicos cobrem inteiros, ponto flutuante, texto, booleanos e estruturas para compor APIs maiores.

EN

The base types cover integers, floating point values, text, booleans, and structures for larger APIs.

Modulos

PT

Bibliotecas sao acopladas por `attach`, mantendo codigo nativo, stdlib e DSLs web no mesmo modelo.

EN

Libraries are attached with `attach`, keeping native code, the standard library, and web DSLs in the same model.

attach {math}

Importa funcoes da biblioteca padrao por nome.

attach {F:path/file.ofs}

Importa um arquivo OFS local explicitamente.

extern vein

Declara simbolos oferecidos pelo runtime ou por C.

core main()

Define o ponto de entrada do programa nativo.

Modos de baixo nivel

PT

Blocos como fracture, abyss, fractal e bedrock existem para experimentos controlados perto do runtime.

EN

Blocks such as fracture, abyss, fractal, and bedrock exist for controlled experiments close to the runtime.

Esses modos sao poderosos e devem ser usados quando a semantica normal da linguagem nao for suficiente.
