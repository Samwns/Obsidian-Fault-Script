ODL

Linguagem de documentos da OFS, independente do formato usado para hospedagem.

ODL não é HTML

ODL (Obsidian Document Language) é uma linguagem declarativa para estruturação de documentos com indentação limpa, suporte a Markdown nativo e nós semânticos. HTML é o target de compilação para navegadores, mantendo ODL como o código-fonte autoral do projeto.

Arquivos .odl são a fonte oficial de documentos web no ecossistema OFS, compilados para HTML no momento do build.

Gramática e estrutura

Cada linha define um nó estrutural, com classes opcionais via `.classe` e IDs via `#id`. A indentação determina a hierarquia de descendência dos elementos.

page.odl
page "OFS Web" "pt"
skin "theme.oes"
flow
  deck.topbar
    title1 "OFS Web"
    link.button "Documentação" "#docs"
  stage#content
    band.docs
      mark "## Documento ODL\nConteúdo formatado com **Markdown**."
      tile.status
        text "Componente estrutural reutilizável"
  spark "app.js"

Componentes ODL

`component nome` define uma unidade estrutural reutilizável e `use nome` instancia o componente dentro da árvore do documento.

components.odl
component notice
  tile.notice
    title2 "Aviso"
    text "Conteúdo reutilizável"

flow
  use notice

Scripts e integração

`wire` carrega scripts JavaScript tradicionais, `spark` importa módulos ES, e `pulse` insere rotinas inline. O backend OFS pode servir o documento via HTTP nativo através de `webserver.ofs`.

Navegador

`wire`, `spark` e `pulse` integram scripts.

Servidor

`webserver.ofs` provê execução HTTP nativa.

Conteúdo

`mark` processa Markdown diretamente na estrutura.

Formatos de distribuição

O compilador emite arquivos HTML e CSS estáticos prontos para hospedagem no GitHub Pages, servidores Nginx, Apache ou CDNs. Os fontes originais permanecem em ODL e OES.

A separação entre fonte declarativo e artefato de distribuição permite adicionar novos alvos de renderização no futuro sem alterar os documentos existentes.
