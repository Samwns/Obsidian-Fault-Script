Modelo ODL

PT

ODL e a linguagem de documentos da OFS. Ela nao substitui o navegador: ela gera HTML padrao como artefato.

Documentos

Fonte .odl compilada pelo launcher OFS.

Componentes

Blocos indentados podem virar funcoes reutilizaveis.

Hospedagem

HTML gerado roda em GitHub Pages, nginx, CDN ou webserver OFS.

Sintaxe propria

PT

ODL usa `page`, `skin`, `flow`, `deck`, `stage`, `band`, `tile`, `mark` e `raw` para ficar mais perto da tematica OFS.

page.odl
page "OFS Web" "pt"
skin "theme.css"
flow
  deck.topbar
    title1 "OFS Web"
    link.button "Documentacao" "#docs"
  stage#content
    band.docs
      mark "## Documentos nativos\nEscreva **ODL**, gere HTML."
      raw ""
  spark "app.js"

Markdown, HTML, JS, PHP e Node

PT

`mark` aceita Markdown, `raw` aceita HTML, `spark` importa JS module, `pulse` injeta JS inline e `server` pode preservar templates PHP.

O objetivo e autorar em ODL sem perder interoperabilidade quando um projeto precisar de codigo legado.
