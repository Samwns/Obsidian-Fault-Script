Documentacao OFS

ODL

Obsidian Document Language: a camada estrutural de documentos para sites OFS.

Documentos

ODL e uma fonte propria compilada nativamente pela OFS.

Componentes

Blocos indentados substituem fechamento repetitivo e podem virar funcoes OFS.

Saida

HTML e artefato gerado para navegador, GitHub Pages e hospedagem comum.

page.odl
page "OFS Web" "pt"
skin "theme.css"
flow
  deck.topbar
    title1 "OFS Web"
    link.button "Documentacao" "#docs"
  stage#content
    band.docs
      mark "## Documentos nativos\nEscreva **ODL**, gere HTML."
      raw ""
  spark "app.js"
FormaUso
page / skin / flowDocumento, estilo e corpo com nomes proprios do OFS.
deck / stage / band / tileEstrutura semantica gerada como nav, main, section e article.
markMarkdown nativo dentro do documento.
rawInterop explicita com HTML quando precisar.
wire / spark / pulse / serverScripts de browser, modulo estilo Node, inline JS e templates PHP.
studioModo local para editar posicionamento visual e exportar OES.
