    hashmap

    namespace hashmap6 funções públicas16%ofs/stdlib/hashmap.ofs

    OFS Standard Library — Hashmap Module Tabela hash inteiro -> inteiro com enderecamento aberto (sondagem linear), escrita 100% em OFS. Cresce automaticamente (fator de carga 0.5).

    forge m = hashmap.new(64)
hashmap.set(m, 42, 7)
forge v = hashmap.get(m, 42, -1)   // 7
hashmap.has(m, 99)                 // false

    Valores que sao ponteiros ou strings podem ser guardados como stone (p as stone) ou como indice para um Array mantido pelo chamador.

    • new
    • count
    • set
    • get
    • has
    • clear
