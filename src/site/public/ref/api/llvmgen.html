    #type_storage_size

    llvmgen
    vein type_storage_size(type_str: obsidian) -> stone

    Monoliths live behind pointers in generated code. They used to receive a fixed 4096-byte allocation, which made normal compiler temporaries consume several GiB during a self-hosted build. Keep the LLVM layout calculation here so every allocation is only as large as its actual fields require.
