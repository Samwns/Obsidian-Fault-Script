    android_input

    namespace ainput5 funções públicas60%ofs/stdlib/android_input.ofs

    OFS Standard Library — android_input: entrada de texto pelo teclado do sistema (Gboard etc.), 100% OFS (JNI)

    attach {F:android_input.ofs}
ainput.open("Titulo", "texto inicial", false)  // false se falhar (last_error)
ainput.poll()      // 1x por quadro: 0 aberto, 1 confirmado (OK), 2 cancelado (voltar/fora)
ainput.text()      // texto atual do EditText (valido enquanto aberto e depois de poll() != 0)
ainput.close()     // fecha o Dialog (poll() != 0 ja fecha sozinho)

    Um android.app.Dialog com um EditText nativo: cursor, selecao, colar, autocompletar e o teclado padrao do aparelho funcionam sem nenhuma classe Java propria. Nao ha listeners: - os botoes sao ToggleButton, que alternam o proprio estado ao toque; poll() le isChecked(); - voltar / tocar fora fecha o Dialog (cancelable) e poll() percebe por isShowing(). So na thread principal (callbacks do android.ofs), como o android_webview.
