    oal_x11

    namespace oal_x118 funções públicas0%ofs/stdlib/oal_x11.ofs

    OFS stdlib — oal_x11: backend desktop da OAL Abre uma janela X11 do tamanho de um celular para testar um app OAL no PC.

    R ou F2   gira (retrato <-> paisagem)
Esc/Backspace  botao voltar
roda do mouse  rola; clique e arraste = toque

    Tamanho padrao: 412x868 dp (Moto G8 Power) com escala 1.0; OAL_SCALE=150 (x100) aumenta, OAL_SHOT=<arquivo.ppm> salva um quadro e sai (testes).
