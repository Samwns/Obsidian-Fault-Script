    47 funções públicas40%ofs/tools/oalc.ofs

    oalc — compilador da OAL (Obsidian Android Language), v0

    OALC_INPUT=app.oal OALC_OUT_DIR=build OALC_TARGET=android|desktop oalc

    Gera, em OALC_OUT_DIR:

    AndroidManifest.xml   (bloco `app`)
<nome>_oal.ofs        (telas, estilos, acoes e ciclo de vida em OFS; usa
                       o stdlib oal_runtime + backend oal_android/oal_x11)
oal_icon.txt          (caminho absoluto do icone PNG, se houver; a CLI
                       copia para res/mipmap)

    Sintaxe: docs/OAL_REFERENCE.md.
