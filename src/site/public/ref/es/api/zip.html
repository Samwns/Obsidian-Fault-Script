    OFS Standard Library — zip: ler e criar arquivos .zip, 100% OFS

    Leitura (inflate do png.ofs; metodos 0 = guardado e 8 = deflate):

    attach {F:zip.ofs}
if (zp.open("/caminho/pacote.zip")) {
    forge i = 0
    while (i < zp.count()) { println(zp.name(i)); i++ }
    zp.extract_all("/destino")            // recusa nomes com ".." ou absolutos
    forge txt = zp.read_text("plugin.json")   // "" se nao existir / falhar
    zp.close()
}
zp.find("a/b.txt") -> indice ou -1;  zp.size(i);  zp.is_dir(i)
zp.extract(i, "/destino/arq")             // cria as pastas do caminho; confere o CRC

    Extracao em blocos (nao trava a interface: o inflate retoma de onde parou):

    if (zp.xbegin(i, "/destino/arq", true)) {          // true = tambem calcula o sha256
    forge r = 0
    while (r == 0) { r = zp.xstep_ms(8) }          // ~8 ms por chamada (ou zp.xstep(bytes))
    // r == 1: gravado e CRC conferido, zp.x_sha = sha256 hex; r == -1: zp.last_error
}
zp.xabort()                                         // cancela e apaga o parcial
zp.xpct() -> 0..100

    Escrita (metodo 0, sem compressao; basta para saves e pacotes pequenos):

    zp.create("/sdcard/MOON/export/x.zip")
zp.add_file("pasta/nome.txt", "/origem/nome.txt")
zp.add_text("plugin.json", "{...}")
zp.finish()

    Limites: sem zip64 (4 GB), sem criptografia, sem multi-volume. O arquivo aberto para leitura fica inteiro na memoria. Um zip por vez em cada modo.
