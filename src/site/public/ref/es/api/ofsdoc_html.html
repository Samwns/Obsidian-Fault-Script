    ofsdoc_html

    55 funciones públicas21%ofs/tools/ofsdoc_html.ofs

    ofsdoc_html: gerador das paginas do ofs doc (parte 2).

    Escreve HTML estatico direto em arquivos (fputs, pedaco por pedaco): o runtime do OFS nao libera strings, entao nenhuma pagina e montada numa string grande. Usado pelo CLI (ofs doc) e pelo build do site (src/site/src/ref.ofs), que injeta a navegacao do Guia via od_nav_guide.

    Convencao de comentario (documentada em docs/TOOLS.md):

    // Resumo em uma linha.
//
// Texto livre; `nome` vira link quando existir no codigo.
//   linhas indentadas viram bloco de codigo
// @param a descricao do parametro a
// @returns descricao do retorno
// @example
//   hashmap.set(m, 1, 2)
