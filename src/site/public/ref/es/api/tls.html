    tls

    namespace tls4 funciones públicas50%ofs/stdlib/tls.ofs

    OFS Standard Library — TLS Module Conexoes TLS (HTTPS) usando o OpenSSL do sistema (libssl/libcrypto 3). Linke com: OFS_LINK_LIBS="-lssl -lcrypto" ofs build app.ofs

    forge fd = net.tcp_connect(net.resolve("example.org"), 443)
forge s = tls.connect(fd, "example.org")      // null se falhar
tls.send(s, "GET / HTTP/1.0\r\nHost: example.org\r\n\r\n")
forge buf = tls.recv_all(s)                    // tls.last_len bytes
tls.close(s)

    Seguranca: o certificado e verificado contra as CAs do sistema e o nome do host e conferido (SSL_set1_host). Falhas ficam em tls.last_error.
