    OFS stdlib — oal_runtime: nucleo de UI de toque da OAL (Obsidian Android Language)

    Desenha a tela de um app OAL num buffer RGBA em software (canvas + raster + ttf) e trata toque, rolagem e navegacao. Nao depende de plataforma:

    - oal_android.ofs  -> NativeActivity / ANativeWindow (stdlib android.ofs)
- oal_x11.ofs      -> janela X11 do tamanho de um celular (testar no PC)

    Layout: arvore de nos do nucleo neutro do OLL (oll.new_node/add_child/ layout_node), com alturas fixas medidas aqui. Retrato e paisagem mudam as colunas da grade, os blocos portrait/landscape e a largura util.

    Contrato (sem ponteiro de funcao para o codigo do app): o arquivo gerado pelo oalc define as veins abaixo; o backend define as oal_backend_*.

    Depends on: oll raster ttf icons png
