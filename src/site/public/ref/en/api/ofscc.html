    #refract_reload

    vein refract_reload(path: obsidian) -> stone

    ofs refract (OFS_REFRACT=1, modo run): o interpretador chama refract_reload quando um arquivo observado muda. Mesmo caminho do inicio (attach -> lexer -> parser -> typeck); os nos novos entram no mesmo pool. Devolve a raiz nova, ou -1 com os erros ja impressos (no stdout, que o interpretador desvia para o stderr durante a chamada).
