    stdlib

    png

    namespace png17 public functions47%ofs/stdlib/png.ofs

    OFS Standard Library — PNG Module Decodificador PNG escrito 100% em OFS, com inflate (zlib/DEFLATE) proprio. Suporta: tons de cinza, RGB, paleta (1/2/4/8 bits), cinza+alfa, RGBA, profundidade 8 (16 bits usa o byte alto). Nao suporta entrelacado (Adam7).

    forge img = png.load("/caminho/foto.png")     // -1 se falhar
png.draw(cv, img, x, y, w, h)                  // desenha escalado
png.draw_cover(cv, img, x, y, w, h)            // preenche cortando (papel de parede)

    Pixels ficam como 0xAARRGGBB (alfa 255 = opaco).
