    OFS Standard Library — strbuf: texto montado aos pedacos

    s = s + x num laco copia o texto inteiro a cada volta. O compilador ja cresce s no lugar quando prova que ninguem mais ve o valor antigo (ver docs/STANDARD_LIBRARY.md, "Strings e memoria"), mas quando o texto passa por varias funcoes ou estruturas, um buffer explicito e o caminho certo:

    attach {strbuf}
forge b: StrBuf = strbuf.create(64)
strbuf.append(b, "linha ")
strbuf.append_int(b, 42)
strbuf.append_char(b, 10)
forge texto = strbuf.to_obsidian(b)   // copia; o buffer continua valendo
strbuf.release(b)

    A capacidade dobra quando enche (append amortizado O(1)). Usa memoria crua do runtime; roda igual no build nativo e no ofs run (F2).
