    The OFS standard library modules reside in ofs/stdlib/. Installed system modules are imported by name using the attach directive: 

    attach {math}
attach {string}
attach {io}

    During local development, specific files can be imported by relative or absolute file paths using the F: prefix: 

    attach {F:../modules/my_module.ofs}

    1. Core Modules

    math.ofs

    Mathematical functions implemented purely in OFS:

    • square(x): Computes the square of a number (x * x).
    • cube(x): Computes the cube of a number (x * x * x).
    • sum_range(start, end): Calculates the inclusive range sum.
    • is_prime(n): Performs prime verification via odd divisor testing.
    • count_digits(n): Counts decimal digits in an integer.
    • sum_digits(n): Sums decimal digits.
    • reverse_number(n): Reverses decimal digits.
    • is_palindrome_number(n): Checks whether a number is numerically palindromic.
    attach {math}

core main() {
    echo(square(12))
    echo(is_prime(97))
}

    string.ofs

    Text manipulation routines built atop runtime primitives:

    • repeat_str(text, count): Repeats a string by the specified count.
    • starts_with_char(text, char_code): Checks if the first byte matches the given ASCII code.
    • is_empty(text): Returns true if the string length is zero.

    The native runtime additionally supplies ofs_str_len, ofs_str_char_at, ofs_str_substr, ofs_str_concat, ofs_str_eq, ofs_str_contains, and numeric formatting conversions.

    strbuf.ofs

    Text buffer whose capacity doubles when full (amortized O(1) append). Use it when text is built in many steps or passes through several functions:

    • strbuf.create(capacity): creates an empty StrBuf.
    • strbuf.append(b, text), strbuf.append_char(b, byte_code), strbuf.append_int(b, n): append to the end.
    • strbuf.to_obsidian(b): returns a copy of the contents (the string does not change if the buffer keeps growing).
    • strbuf.length(b), strbuf.clear(b) (empties it, keeps the capacity), strbuf.release(b) (frees the memory).
    attach {strbuf}

core main() {
    forge b: StrBuf = strbuf.create(64)
    strbuf.append(b, "total: ")
    strbuf.append_int(b, 42)
    echo(strbuf.to_obsidian(b))
    strbuf.release(b)
}

    Native code only for now (it uses raw runtime memory; ofs run cannot reach the Rift yet).

    Strings and memory. Strings have no GC or reference counting: t = s makes both variables point to the same text. The native compiler only reuses or frees memory when it proves nobody else sees the value: s = s + x / s += x on a local variable that is never copied elsewhere grow in place; the intermediate parts of a + b + c and an f(a + b) whose parameter is not stored are freed; local arrays that do not escape are freed at the end of their scope. If the variable is copied, stored in a field/array or passed to a function that keeps it, everything works as before (a new copy on every +).

    io.ofs

    Terminal and console input/output:

    • prompt(message): Prints the message and reads a line from standard input.
    • print_separator(character, count): Emits a repeating delimiter line.
    • print_header(title): Formats and outputs a console section banner.

    terminal_colors.ofs

    ANSI escape code constants and helpers for styled terminal output on compatible emulators.

    2. Web Stack Modules

    odl.ofs

    Programmatic API for constructing ODL / HTML semantic document trees:

    • Structural elements: document, meta, css, icon, script, script_module.
    • Semantic containers: div, section, article, nav, header, main, footer.
    • Typography and text: a, img, p, h1, h2, h3, strong, span.
    • Forms and lists: ul, ol, li, form, label, input, button.
    • Tables and code: table, table_id, code_block.
    • Low-level nodes: tag, void_tag, attr, text.

    oes.ofs

    Programmatic API for generating OES / CSS styling rules:

    • prop(name, value): Emits individual style properties.
    • rule(selector, body): Declares selector rule blocks.
    • media(query, body) / supports(query, body) / layer(name, body): Responsive groupings and cascade layers.
    • keyframes(name, frames) / frame(step, body): Keyframe animation sequences.
    • var(name, value) / use(name): Token declarations and references.
    • transition(...) / animation(...): Motion primitives.

    webserver.ofs

    Native HTTP server and protocol helpers:

    • HTTP method constants (GET, POST, PUT, DELETE).
    • HTTP status codes (200, 201, 400, 404, 500) and descriptions (status_text).
    • MIME type resolution (get_mime_type) for HTML, CSS, JS, JSON, text, ODL, and OES.
    • HTTP response encapsulation (http_response) with headers.
    • Structured JSON fragment emission (json_string, json_number).
    • Request logging utilities (log_request).
    • Execution loops: serve_once, serve_forever, serve_html_once, serve_html_forever.

    webui.ofs

    Reusable UI component library built on ODL and OES:

    • Themes: theme_dark(), theme_light().
    • Layout components: page, nav, hero, panel, grid, card, stack.
    • Controls: button.
    • Server launcher: serve.

    3. Native Visual Modules

    canvas.ofs

    Low-level 2D raster pixel buffer rendering:

    • Surface allocation and deallocation (canvas.create, canvas.destroy).
    • Surface clearing (canvas.clear).
    • Drawing primitives: individual pixels (set_pixel), rectangles, lines, and bitmap font text.
    • Image export to binary PPM without third-party libraries.

    window.ofs

    Native desktop window lifecycle and event loops:

    • Window creation and teardown (window.create, window.destroy).
    • Event polling (window.poll).
    • Native platform drivers for X11 on Linux and Win32 on Windows.

    ui.ofs

    Immediate-mode graphical user interface controls:

    • Bounding box primitives (UiRect).
    • Theme styling (UiStyle, ui.dark(), ui.light()).
    • Basic widgets: buttons, labels, and text dimension measurement.

    raster.ofs

    Antialiased vector rasterizer (signed-area accumulation). Paths (move_to, line_to, quad_to, cubic_to, close), shapes (add_round_rect, add_circle, add_capsule, add_arc_stroke) and one-call helpers (fill_round_rect, fill_circle, stroke_line, stroke_round_rect). Composites onto a Canvas honoring alpha and clipping.

    ttf.ofs

    Pure-OFS TrueType fonts: ttf.load(path), ttf.draw(cv, font, size, x, baseline, text, color), ttf.width, ttf.ascent/descent/line_height, ttf.ellipsize, ttf.draw_centered. UTF-8, composite glyphs (accents), glyph cache and subpixel positioning. Multi-line text: ttf.wrap(font, size, text, max_width) word-wraps and returns an Array<obsidian> (honours \n); ttf.draw_wrapped(cv, font, size, x, y, max_width, line_height, text, color, max_chars) draws the wrapped text from top y and returns the line count (max_chars < 0 draws everything; useful for a typewriter effect). CFF outlines (OpenType/PostScript, Type 2 charstrings with local/global subrs and CID fonts with FDArray/FDSelect, hints ignored) besides glyf. TTC collections: ttf.load_face(path, i), ttf.load_face_named(path, "CJK JP") (matches the face name), ttf.face_count. Per-glyph fallback: ttf.set_fallback(font) or ttf.set_fallback_file(path, face_name) (loaded only when the first glyph is missing); draw/width/wrap/ellipsize use the fallback when the font lacks the character; ttf.has_glyph(font, cp). The rasterized glyph cache restarts past ttf.pool_limit pixels (ttf.clear_cache()). E.g. Roboto + /system/fonts/NotoSansCJK-Regular.ttc on Android for Japanese and arrows.

    x11win.ofs

    Native X11 window: open, present(canvas), poll() → EV_KEY/EV_MOUSE_DOWN/EV_MOUSE_UP/EV_MOUSE_MOVE/EV_WHEEL/EV_RESIZE/EV_CLOSE, fields ev_x, ev_y, ev_button, ev_key (keysym), ev_text (UTF-8, with dead keys), ev_mods; set_cursor, set_icon, set_title, now_ms, sleep_ms.

    icons.ofs

    24×24 vector icons: icons.draw(cv, icons.BACK, x, y, size, color) and icons.draw_centered. Constants BACK, FORWARD, RELOAD, HOME, PLUS, CLOSE, LOCK, INFO, STAR, MENU, SEARCH, GLOBE, DOWNLOAD, HISTORY, SETTINGS, PROFILE, STOP, FILE, BOOKMARK, SHIELD, PLUGIN, SAVE, FOLDER, PLAY, HAMBURGER, GAMEPAD; icons.by_name("plugins") accepts names and aliases (import, load, config...). UI icons added for OAL and Moon: AUTO, SKIP, BACKLOG, EYE, EYE_OFF, ROTATE, PORTRAIT, LANDSCAPE, TRASH, EDIT, IMAGE, VOLUME, TEXT, PALETTE, CHECK, STORAGE, KEYBOARD, BACKSPACE, SHIFT, PAUSE, JOYSTICK, SPACE, CHEVRON, RESIZE, TABS. Game engine icons: WINDOWS (PC program window), RENPY (speech bubble: visual novel), UNITY (isometric cube: 3D engine), MOON, UNKNOWN. icons.by_name also accepts Portuguese names (lixeira, retrato, paisagem, teclado, joystick...).

    android.ofs

    Pure-OFS Android backend (NativeActivity, aarch64, API 26+): exports ANativeActivity_onCreate, wires callbacks with fault_addr, input via AInputQueue_attachLooper, frames via AChoreographer. The program defines android_event(ev). Functions: lock/unlock_post/fill_rect/blit, request_frame, finish, set_orientation (JNI), internal_data_path, external_data_path, log/log_tag. See ANDROID.md.

    oal_runtime.ofs, oal_android.ofs, oal_x11.ofs

    OAL runtime: touch widgets (bar, button, icon, list, grid, card, fab, D-pad), styles with pressed state and opacity, scrolling, navigation, portrait/landscape, drawn with canvas/raster/ttf/icons on top of the neutral oll.ofs layout core. oal_android.ofs is the Android backend; oal_x11.ofs (phone-sized desktop window) is experimental. See OAL_REFERENCE.md.

    wav.ofs

    Pure-OFS WAV (RIFF) decoder with no platform dependency: wav.load(path) (-1 on failure), wav.decode(ptr, len), wav.pcm(s) (pointer to interleaved i16 samples), wav.frames, wav.channels, wav.rate, wav.free. Supports 8/16-bit PCM and Microsoft ADPCM. wav.from_pcm(ptr, frames, channels, hz) registers i16 PCM already in memory.

    audio_android.ofs

    AAudio sound output (Android 8+): audio.open() (44.1 kHz, stereo, i16), audio.play(channel, sound, loop), stop, stop_all, set_volume(channel, 0-100), set_master, playing, pause/resume/close, and audio.pump() once per frame. The mixer runs on the audio thread and only touches raw memory; ofs build --target android links -laaudio. See ANDROID.md. audio.position(channel): frames already played of the channel's sound (clock for video sync).

    avi.ofs

    AVI reader (RIFF/OpenDML) and Microsoft Video 1 decoder (CRAM/MSVC, 16-bit) in pure OFS: avi.open(path), codec (FourCC), supported, width/height/frames/us_per_frame, avi.decode(v, frame, dst) (0xRRGGBB per pixel; sequential, delta frames), audio_format/audio_channels/audio_rate/audio_bits, read_audio (PCM of all ##wb chunks) + audio_bytes, close. Each frame is read from disk on demand. Output is bit-identical to ffmpeg. Other codecs (Xvid/MPEG-4, Indeo) are not decoded.

    hashmap.ofs

    Integer-to-integer hash table: hashmap.new(cap), set, get(m, key, fallback), has, count, clear.

    tls.ofs

    HTTPS connections using the system OpenSSL: tls.connect(fd, host) (SNI + certificate and hostname verification), tls.send, tls.recv_all (tls.last_len), tls.close, tls.last_error. Link with OFS_LINK_LIBS="-lssl -lcrypto".

    png.ofs

    Pure-OFS PNG decoder (own inflate/zlib): png.load(path), png.width, png.height, png.draw(cv, img, x, y, w, h), png.draw_cover, png.draw_region. Pixels as 0xAARRGGBB.

    zip.ofs

    Read and create .zip in pure OFS (inflate from png.ofs): zip.open(path), count, name(i), size(i), is_dir(i), find(name), read(i) (zip.data_ptr/data_len, free_data), read_text(name), extract(i, dest), extract_all(dir) (refuses .. and absolute paths; checks CRC), close; stored (uncompressed) writing: create, add_file, add_text, add_bytes, finish. No zip64/encryption. png.inflate_raw exposes raw deflate. Chunked extraction (keeps the UI responsive): zip.xbegin(i, dest, hash) opens the entry; call zip.xstep(bytes) or zip.xstep_ms(ms) once per frame until it returns 1 (written, CRC checked, zip.x_sha holds the sha256 if hash) or -1 (zip.last_error; the partial file is removed); zip.xpct() gives 0..100 and zip.xabort() cancels. Inflate resumes where it stopped (png.inflate_begin/inflate_step/inflate_take/inflate_abort) with its own state, so png.load may run between steps.

    sha256.ofs

    sha256.file(path) and sha256.bytes(ptr, n) (64 lowercase hex; 64 KB blocks), sha256.crc32_update(crc, ptr, n).

    android_http.ofs, android_webview.ofs

    HTTP/HTTPS through HttpURLConnection via JNI and a full-screen WebView in a Dialog, no Java of our own. See ANDROID.md. icons.ofs gained RPGM and TYRANO; oal_runtime.ofs gained colorpicker, set_palette_full, hsv_to_rgb.

    4. Systems and Low-Level Modules

    bedrock.ofs

    Explicit memory management:

    • Manual cell and buffer allocation (bedrock_cell_new, bedrock_cell_drop).
    • Direct pointer dereferencing and arithmetic.
    • Memory arenas and scoped regions.

    bedrock_packet.ofs

    Binary buffer encoding and decoding for low-level network protocols.

    rift.ofs

    Rift layer: declaring and calling native functions from system libraries through the system calling convention (known technically as the C ABI; it involves no C code).

    memory_modes.ofs

    Experimental interfaces for explicit memory tracking and access boundary validation.

    5. Support and Compatibility Modules

    test_lib.ofs

    Testing harness used for language verification and regression testing.

    ofshtml.ofs

    Legacy HTML helpers maintained for backward compatibility. New web projects should use odl.ofs.
