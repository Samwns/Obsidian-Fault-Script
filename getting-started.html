Documentacao OFS

Comecando

Da instalacao ao primeiro executavel e site nativo em OFS.

1. Instale

Baixe a release para sua distro, macOS, Windows ou VS Code.

2. Crie

Use .ofs para logica nativa, .odl para documentos e .oes para efeitos.

3. Verifique

Rode check antes de run, build, odl ou oes para validar o projeto.

terminal
dist/ofs check app.ofs
dist/ofs run app.ofs
dist/ofs build app.ofs -o app
./app

dist/ofs odl page.odl -o index.html
dist/ofs oes site.oes -o site.css
Gerado por ODL e OES em OFS.
