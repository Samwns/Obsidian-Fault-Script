Getting Started

From installation to the first native OFS executable.

1. Install

Download the latest release for Linux, macOS or Windows.

2. Create

Write a .ofs file with core main() as the entry point.

3. Verify

Use check before run or build to validate the program.

terminal
dist/ofs check app.ofs
dist/ofs run app.ofs
dist/ofs build app.ofs -o app
./app
