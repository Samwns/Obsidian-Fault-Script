Sintaxe propria

PT

OES preserva o poder do CSS, mas usa nomes como `gem`, `paint`, `fill`, `ink`, `curve`, `space`, `veil` e `pulse`.

EN

OES preserves CSS power while using names such as `gem`, `paint`, `fill`, `ink`, `curve`, `space`, `veil`, and `pulse`.

theme.oes
gem accent "#29e0bd"
gem surface "#101722"
paint .button
  fill "$accent"
  curve "8px"
  transition "transform .2s ease"
veil "(max-width: 700px)"
  paint .grid
    grid-cols "1fr"
pulse "enter"
  rise
    opacity "0"
  rest
    opacity "1"

Motion e layout

PT

`pulse`, `rise`, `rest` e `atNN` organizam animacoes. O editor pode usar essa fonte para ajustes visuais e exportar OES.

EN

`pulse`, `rise`, `rest`, and `atNN` organize animations. The editor can use this source for visual adjustments and export OES.
