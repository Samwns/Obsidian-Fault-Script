OES nao e CSS

OES e uma linguagem de efeitos e sistemas visuais. Sua fonte organiza tokens, regras, contextos responsivos, capacidades, camadas e linhas do tempo. CSS e somente o target web atual para renderizadores existentes.

A semantica OES permanece a mesma mesmo quando um target representa uma forma com uma propriedade CSS equivalente.

Gemas e valores

`gem` declara valores nomeados usados por outras regras com `$nome`. Isso centraliza cor, espaco, tipografia e movimento sem exigir que o autor manipule a sintaxe do target.

tokens.oes
gem accent "#29e0bd"
gem spacing "16px"

paint .action
  fill "$accent"
  space "$spacing"

Pintura, layout e contexto

`paint` seleciona uma unidade visual. `veil` altera regras por contexto responsivo, `guard` condiciona por capacidade e `strata` separa camadas ordenadas. Propriedades sem alias podem ser preservadas para interoperabilidade enquanto o vocabulario OES cresce.

theme.oes
gem accent "#29e0bd"
gem surface "#101722"
paint .button
  fill "$accent"
  curve "8px"
  transition "transform .2s ease"
veil "(max-width: 700px)"
  paint .grid
    grid-cols "1fr"
pulse "enter"
  rise
    opacity "0"
  rest
    opacity "1"

Pulsos e quadros

`pulse` nomeia um efeito. `rise`, `rest` e `atNN` descrevem quadros da linha do tempo. A duracao e a aplicacao do efeito ficam em regras `paint`, permitindo reutilizar o mesmo pulso.

motion.oes
pulse "enter"
  rise
    opacity "0"
  at50
    opacity ".6"
  rest
    opacity "1"

paint .panel
  animation "enter .24s ease"

Edicao visual segura

O modo Studio somente ativa em localhost e exige o parametro `ofs-studio=1`. Elementos `move` podem ser reposicionados e exportam regras OES; a ferramenta nao grava fonte automaticamente nem executa em producao.

O posicionamento exportado deve ser revisado como codigo. Isso evita que uma ferramenta visual altere silenciosamente layout responsivo ou acessibilidade.

Targets visuais

O target web traduz o sistema visual OES para regras aceitas pelos navegadores. Outros targets podem mapear gemas, pintura e pulsos para renderizadores nativos sem tornar OES dependente de CSS.
