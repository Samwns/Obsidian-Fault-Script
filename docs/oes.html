OES nao e CSS

OES e uma linguagem de efeitos e sistemas visuais. Sua fonte organiza gemas, regras, contextos responsivos, capacidades, camadas e linhas do tempo. CSS e somente o target web atual para renderizadores existentes.

OES evita heranca acidental: tokens e camadas tornam o escopo explicito, e o target web mapeia isso para variaveis, regras encapsuladas e keyframes.

Gemas e valores

gem declara valores nomeados usados por outras regras. A sintaxe atual com strings continua aceita; a forma tipada declara a categoria do valor, como Color ou Size.

tokens.oes atual
gem accent "#a978ff"
gem spacing "16px"

paint .action
  fill "$accent"
  space "$spacing"
tokens.oes tipado
gem accent: Color = "#a978ff"
gem spacing: Size = "16px"

Pintura, layout e contexto

paint seleciona uma unidade visual. veil altera regras por contexto responsivo, guard condiciona por capacidade e strata separa camadas ordenadas. A forma com chaves permite agrupar contexto dentro da regra sem depender so da indentacao.

theme.oes
paint .button
  fill(accent)
  curve("8px")
  transition("transform .2s ease")

  veil("(max-width: 700px)") {
    grid-cols("1fr")
    space(spacing)
  }
end

Pulsos e quadros

pulse nomeia um efeito. rise, rest e atNN descrevem quadros da linha do tempo. No target web, pulsos compilam para @keyframes.

motion.oes
pulse "enter"
  rise {
    opacity("0")
  }
  at50 {
    opacity("0.6")
  }
  rest {
    opacity("1")
  }
end

Edicao visual segura

O modo Studio somente ativa em localhost e exige o parametro ofs-studio=1. Elementos move podem ser reposicionados e exportam regras OES; a ferramenta nao grava fonte automaticamente nem executa em producao.

Studio deve aplicar edicoes sem injetar inline styles no codigo fonte original. O posicionamento exportado continua sendo revisado como codigo.

Targets visuais

Gemas viram variaveis CSS ou tokens extraidos, paint vira classe encapsulada, veil vira consulta responsiva e pulse compila para keyframes. Outros targets podem mapear a mesma semantica para renderizadores nativos.
