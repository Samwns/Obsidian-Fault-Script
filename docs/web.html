Stack web OFS

A stack separa a fonte do projeto dos artefatos de distribuicao. ODL e OES sao versionados como linguagem; HTML, CSS e JS sao saidas geradas para navegadores atuais.

1. ODL
Documento, hierarquia e componentes.
2. OES
Gemas, layout, camadas e motion.
3. OFS
Servidor, dados e geracao de target.
4. Host
Pages, CDN, nginx ou webserver OFS.

Target web

Browsers executam HTML/CSS/JS. Por isso o build web gera uma arvore DOM limpa, stylesheet compilado e scripts conectados por wire, spark e pulse. O target nao muda a identidade da fonte.

site.ofs
attach {odl}
attach {oes}
attach {webserver}

core main() {
    forge head = odl.css("site.css")
    forge body = odl.main("app", odl.h1("Documento ODL"))
    forge html = odl.document("pt", "OFS", "site", head, body)
    webserver.serve_html_forever(8080, html)
}

Componentes e escopo

Componentes ODL devem ter contrato de props quando a forma tipada estiver ativa. OES usa gem, paint, veil e strata para evitar dependencia em cascata global.

ODL

Estrutura, ids, classes, componentes e pontos de comportamento.

OES

Tokens visuais, regras encapsuladas, contextos responsivos e animacoes.

webui

Composicao de paginas e componentes por funcoes OFS.

webserver

Entrega HTTP simples para desenvolvimento e demos nativas.

Estado e atualizacao

A direcao tecnica e gerar atualizacoes diretas nos nos reais, sem DOM virtual obrigatorio. Em desenvolvimento, Hot State Replacement deve aplicar mudancas visuais sem recarregar a pagina e sem perder valores digitados.

A implementacao deve preservar a tipagem OFS existente. Se uma proposta de ODL/OES tipado ficar mais fraca que o type checker atual, ela nao substitui o modelo atual.

Benchmark web

As metricas web devem medir etapas separadas: parse ODL, parse OES, emissao HTML, emissao CSS, tamanho final e tempo de hot update. Esses numeros nao devem ser misturados com CPU nativa do benchmark principal.

Interoperabilidade

ODL permite Markdown, HTML bruto explicito e scripts. OES aceita propriedades do target quando nao existe alias proprio. Isso facilita migracao sem transformar HTML/CSS na fonte oficial.
