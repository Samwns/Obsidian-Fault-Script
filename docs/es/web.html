Web

La stack web nativa de OFS.

Capas web

OFS contiene la logica nativa, ODL describe documentos, OES define diseno y movimiento, webserver sirve HTTP y webui ofrece componentes.

site.ofs
attach {odl}
attach {webserver}

core main() {
    forge html = odl.document("es", "Sitio", "OFS Web", "", odl.h1("Hola"))
    webserver.serve_html_forever(8080, html)
}

Navegador

El navegador recibe HTML, CSS y JavaScript generados. Los archivos ODL y OES permanecen como fuente del proyecto.
