Primeros pasos

De la instalacion al primer ejecutable y pagina web en OFS.

Instalacion

Descarga el paquete para tu sistema desde la pagina de descargas y usa el comando `ofs`.

Abrir descargasComandos CLI

Primer ejecutable

Crea `app.ofs`, verificalo con `check`, ejecutalo con `run` y genera un binario nativo con `build`.

terminal
ofs check app.ofs
ofs run app.ofs
ofs build app.ofs -o app
./app

Primer documento web

Escribe un programa OFS que use `attach {odl}` y `attach {oes}` para construir documentos y estilos, compilalo y ejecútalo para emitir HTML y CSS listos para alojamiento estatico.
