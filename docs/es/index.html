OFS: lenguaje compilado, runtime nativo y DSLs web propios.

Obsidian Fault Script incluye un compilador self-hosted que genera LLVM IR, enlaza un runtime nativo y trae ODL/OES como lenguajes fuente para sitios web.

EmpezarDescargasGitHub
example.ofs
attach {odl}
attach {oes}

vein page() -> obsidian {
    forge head = odl.css("site.css")
    forge body = odl.h1("OFS Web")
    return odl.document("pt", "OFS", "site oficial", head, body)
}

Componentes tecnicos

El ecosistema separa compilador, runtime, biblioteca estandar, herramientas web y empaquetado.

Self-hosted

El lexer, el parser, el verificador de tipos y la generacion LLVM viven en el propio compilador OFS.

Nativo

La salida es LLVM IR enlazado con el runtime nativo de OFS para generar ejecutables.

Hibrido

Consola, canvas/window nativo y sitios con webserver y webui en el mismo ecosistema.

ODL + OES

ODL describe documentos; OES define estilo, efectos, responsividad y animaciones.

site.ofs
attach {odl}
attach {oes}
attach {webserver}

core main() {
    forge head = odl.css("site.css")
    forge body = odl.main("app", odl.h1("OFS Web"))
    webserver.serve_html_forever(8080, odl.document("es", "OFS", "site", head, body))
}
