Bibliotecas base

A base cobre matematica, texto, entrada/saida e terminal. Esses modulos aparecem em exemplos, ferramentas do compilador e pequenos programas de linha de comando.

math.ofs

Funcoes numericas escritas em OFS: `square`, `cube`, `sum_range`, `is_prime`, `count_digits`, `sum_digits`, `reverse_number` e `is_palindrome_number`. Use quando quiser logica matematica comum sem depender direto do runtime.

string.ofs

Utilitarios de texto sobre os builtins do runtime: `repeat_str`, `starts_with_char` e `is_empty`. Use para manipulacao simples de `obsidian` em ferramentas, parsers e exemplos.

io.ofs

Entrada e saida de terminal: `prompt`, `print_separator` e `print_header`. Use em CLIs pequenas e exemplos interativos.

terminal_colors.ofs

Constantes ANSI e helpers para imprimir texto colorido no terminal. Use para mensagens de status, erros e ferramentas de desenvolvimento.

base.ofs
attach {math}
attach {string}
attach {io}

core main() {
    print_header("Demo")
    echo(square(9))
    echo(repeat_str("OFS", 2))
}

Bibliotecas web

A stack web nao e externa: ODL, OES, webserver e webui fazem parte da biblioteca padrao. ODL gera documento, OES gera visual, webserver serve HTTP e webui entrega componentes prontos.

odl.ofs

Construtor de documentos. Expoe `document`, `tag`, `void_tag`, `section`, `article`, `nav`, `main`, `a`, `img`, `code_block`, `table` e helpers semanticos. Use para gerar HTML a partir de OFS.

oes.ofs

Construtor de efeito visual. Expoe `prop`, `rule`, `media`, `supports`, `layer`, `keyframes`, `frame`, `var`, `use`, `transition` e `animation`. Use para gerar CSS sem manter CSS como fonte principal.

webserver.ofs

Servidor HTTP nativo e helpers de resposta. Define MIME types, status HTTP, `http_response`, `json_string`, `json_number`, `get_mime_type`, `serve_once`, `serve_forever`, `serve_html_once` e `serve_html_forever`.

webui.ofs

Componentes web prontos: tema, stylesheet, page, nav, hero, button, panel, grid, card, stack e `serve`. Use para criar uma pagina OFS rapidamente sem escrever toda a estrutura ODL.

site.ofs
attach {odl}
attach {oes}
attach {webserver}

core main() {
    forge page = odl.document("pt", "Site", "feito em OFS", odl.css("site.css"), odl.h1("OFS Web"))
    webserver.serve_html_forever(8080, page)
}

UI nativa e visual

Canvas, window e ui existem para interfaces nativas experimentais. Eles nao substituem ODL/OES: sao para janela local, desenho e prototipos interativos fora do navegador.

canvas.ofs

API de desenho 2D ligada ao runtime: abre area visual, desenha pontos, linhas, retangulos e formas simples. Use para demos, jogos pequenos e visualizacao.

window.ofs

Janela nativa experimental. Centraliza abertura, atualizacao e fechamento de janela quando o runtime oferece suporte.

ui.ofs

Helpers de UI imediata: medidas, texto, caixas e controles simples para prototipos nativos.

ofshtml.ofs

Helpers legados de HTML usados durante a transicao para ODL. Use apenas quando estiver migrando codigo antigo.

Sistema, memoria e FFI

bedrock, bedrock_packet, memory_modes e rift sao camadas avancadas. Elas existem para experimentar baixo nivel com nomes explicitos, sem esconder risco dentro da sintaxe comum.

bedrock.ofs

Primitivos de baixo nivel para regioes e ponteiros. Use somente quando precisar trabalhar perto da representacao de memoria.

bedrock_packet.ofs

Estruturas de pacote para comunicacao experimental. Serve para organizar dados binarios/protocolares em camadas futuras.

memory_modes.ofs

Experimentos de modos de memoria da linguagem. Ajuda a testar limites entre codigo seguro e codigo explicitamente baixo nivel.

rift.ofs

Superficie experimental de FFI com ABI C. Use para declarar chamadas externas quando a stdlib comum nao cobre o caso.

Teste e importacao

A stdlib tambem define convencoes de importacao e apoio a testes. Use imports por nome para codigo instalado e imports por caminho durante desenvolvimento local.

core.ofs

Modulo base reservado para convencoes de nucleo. Ele existe para estabilizar imports e organizar futuras funcoes comuns.

test_lib.ofs

Helpers para exemplos e testes. Use para criar verificacoes pequenas que rodam pelo launcher `ofs`.

attach {F:...}

Importacao direta por caminho. Use quando a biblioteca ainda nao esta instalada como pacote.

attach {nome}

Importacao por nome a partir da stdlib ou de bibliotecas instaladas. Use no codigo final distribuido.
