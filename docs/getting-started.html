Primeiro executavel

PT

Crie `app.ofs`, valide com `check`, rode com `run` e gere um binario com `build`.

EN

Create `app.ofs`, validate with `check`, run with `run`, and build a native binary with `build`.

terminal
ofs/dist/ofs check app.ofs
ofs/dist/ofs run app.ofs
ofs/dist/ofs build app.ofs -o app
./app

ofs/dist/ofs odl page.odl -o index.html
ofs/dist/ofs oes site.oes -o site.css

Primeiro site

PT

Crie `page.odl` e `site.oes`. A OFS gera HTML/CSS para qualquer hospedagem estatica.

EN

Create `page.odl` and `site.oes`. OFS generates HTML/CSS for any static host.

1. Install

Escolha o pacote da sua plataforma e instale o launcher `ofs`.

2. Create

Use .ofs para logica, .odl para documento e .oes para efeito visual.

3. Verify

Rode `check` antes de compilar ou publicar.
