# Documentacao OFS

Esta pasta agrupa a documentacao tecnica em portugues para Obsidian Fault Script.

- Comece por [Getting Started](../GETTING_STARTED.md).
- Leia a [Referencia da Linguagem](../LANGUAGE_REFERENCE.md) para sintaxe, tipos, modulos e modos de baixo nivel.
- Use [Referencia ODL](../ODL_REFERENCE.md) e [Referencia OES](../OES_REFERENCE.md) para as linguagens web nativas.
- Use [Web UI](../WEB_UI.md) para stack web OFS, Go Live, hospedagem estatica e interoperabilidade com navegador.
- Use [Arquitetura do Compilador](../COMPILER_ARCHITECTURE.md) para entender o compilador self-hosted e o pipeline LLVM.

O site oficial em `docs/*.html` e gerado por fonte OFS em `src/site/src/`.
