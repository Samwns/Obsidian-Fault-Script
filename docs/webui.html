Configuração de WebTheme

`WebTheme` centraliza definições de paleta de cores (`bg`, `surface`, `text`, `accent`), bordas e espaçamentos. Alterações no tema refletem diretamente na folha de estilo emitida.

theme.ofs
forge theme = webui.theme_light()
theme.accent = "#a978ff"
theme.radius = 4

Componentes reutilizáveis

As funções do módulo `webui` retornam strings `obsidian`, permitindo composição funcional direta sem estados ocultos.

FunçãoDescrição do componente
theme_dark / theme_lightEstrutura WebTheme com paleta de cores, tipografia, bordas e espaçamentos.
stylesheetGera o bloco CSS baseado na configuração do tema ativo.
pageGera o documento HTML completo com viewport e folha de estilo embutida.
navBarra de navegação superior com logotipo e links.
heroSeção de destaque com título, texto de apoio e botões de chamada.
buttonBotão de ação estilizado com link de navegação.
panel / grid / card / stackContêineres estruturais para layout em grade e colunas flexíveis.
serveConstrói a página e inicia o servidor HTTP nativo.

Composição de páginas

O exemplo abaixo demonstra a criação de uma barra de navegação, seção de destaque e grade de cartões atendidos via servidor nativo.

webui.ofs
attach {webui}

core main() {
    forge body = webui.nav("OFS", webui.button("Docs", "#docs"))
    body = body + webui.grid(webui.card("ODL", "Documentos") + webui.card("OES", "Efeitos"))
    webui.serve(8080, "OFS Web", body)
}

Recarga automática com Go Live

A extensão do VS Code reconhece arquivos com `attach {webui}`, compila o projeto nativo e abre o servidor com recarga automática durante edições.
