Servidor HTTP nativo

O módulo `webserver.ofs` interage diretamente com as funções de socket do runtime nativo. Permite servir respostas HTML, JSON e arquivos locais sem dependências externas.

server.ofs
attach {odl}
attach {webserver}

core main() {
    forge body = odl.h1("Servidor OFS") + odl.p("", "Resposta gerada pela linguagem")
    forge html = odl.document("pt", "Servidor OFS", "Exemplo HTTP", "", body)
    webserver.serve_html_forever(8080, html)
}

Construção de respostas

A função `http_response` gera as linhas de status HTTP, headers `Content-Type` e `Content-Length`, encerrando com o corpo da mensagem.

FunçãoParâmetrosRetorno e efeito
status_textcódigoRetorna o texto padrão associado ao status HTTP.
http_responsestatus, content_type, bodyMonta resposta HTTP completa com headers e corpo.
json_stringchave, valorGera um fragmento de string JSON formatado.
json_numberchave, númeroGera um fragmento numérico JSON formatado.
get_mime_typenome de arquivoDetecta o MIME type a partir da extensão do arquivo.
log_requestmétodo, caminho, statusExibe linha de log de requisição no terminal.
serve_onceporta, tipo, corpoAtende uma única conexão HTTP e retorna.
serve_foreverporta, tipo, corpoInicia o loop contínuo de atendimento HTTP.

Loops de execução

Use `serve_once` para verificações pontuais e testes automatizados. Use `serve_forever` ou `serve_html_forever` para manter o servidor ativo atendendo requisições.

json_server.ofs
attach {webserver}

core main() {
    forge body = "{" + json_string("language", "OFS") + "," + json_number("version", 1) + "}"
    webserver.serve_forever(8080, MIME_JSON, body)
}

Hospedagem estática vs processo nativo

Para documentações e sites institucionais, compile ODL e OES diretamente para HTML e CSS estáticos. Para APIs e páginas dinâmicas, execute o binário nativo compilado com `webserver.ofs`.
