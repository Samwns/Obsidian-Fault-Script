Como o servidor funciona

O modulo chama funcoes de socket do runtime nativo. O programa prepara um corpo imutavel, escolhe o MIME type e inicia um loop de atendimento. A implementacao atual e adequada para desenvolvimento, exemplos e respostas estaticas; roteamento dinamico completo ainda e uma etapa futura.

server.ofs
attach {odl}
attach {webserver}

core main() {
    forge body = odl.h1("Servidor OFS") + odl.p("", "Resposta gerada pela linguagem")
    forge html = odl.document("pt", "Servidor OFS", "Exemplo HTTP", "", body)
    webserver.serve_html_forever(8080, html)
}

Metodos, status e MIME types

As constantes evitam repetir strings e numeros HTTP no programa. ODL e OES tambem recebem MIME proprio para servir o fonte durante inspecao e ferramentas locais.

GrupoValoresUso
MetodosHTTP_GET, HTTP_POST, HTTP_PUT, HTTP_DELETE, HTTP_PATCHPadronizam nomes de metodos.
StatusHTTP_200, HTTP_201, HTTP_400, HTTP_404, HTTP_500Codigos usados por helpers de resposta.
MIMEMIME_JSON, MIME_HTML, MIME_TEXT, MIME_CSS, MIME_JS, MIME_ODL, MIME_OESContent-Type de respostas e fontes.

Construcao de respostas

`http_response` monta a linha de status, Content-Type, Content-Length, Connection e corpo. Os helpers JSON atuais criam fragmentos; objetos completos ainda precisam concatenar chaves e delimitadores.

FuncaoParametrosRetorno e efeito
status_textcodigoConverte status conhecido em texto HTTP.
http_responsestatus, content_type, bodyMonta cabecalhos, Content-Length e corpo.
json_stringchave, valorCria um par JSON textual.
json_numberchave, numeroCria um par JSON numerico.
get_mime_typenome de arquivoDetecta MIME por extensao comum.
log_requestmetodo, caminho, statusImprime uma linha de log.
serve_onceporta, tipo, corpoAtende uma conexao e retorna.
serve_foreverporta, tipo, corpoAtende conexoes ate o processo parar.

Escolha entre once e forever

Use `serve_once` em teste automatizado ou quando uma unica requisicao basta. Use `serve_forever` para um processo local persistente. As variantes `serve_html_*` preenchem `MIME_HTML` automaticamente.

json_server.ofs
attach {webserver}

core main() {
    forge body = "{" + json_string("language", "OFS") + "," + json_number("version", 1) + "}"
    webserver.serve_forever(8080, MIME_JSON, body)
}

Quando usar hospedagem estatica

Para documentacao, portfolio e arquivos que nao mudam por requisicao, compile ODL/OES e publique HTML/CSS. Para um processo local OFS, compile o programa servidor e execute o binario. O servidor atual nao substitui um proxy de producao com TLS, cache e limites de conexao.
