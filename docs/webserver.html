Servidor nativo

PT

O modulo webserver sobe HTTP a partir de um executavel OFS. Ele serve HTML gerado por ODL ou conteudo montado por funcoes.

EN

The webserver module starts HTTP from a native OFS executable. It serves ODL-generated HTML or content assembled by functions.

server.ofs
attach {webserver}

core main() {
    webserver.serve_html_forever(8080, "
OFS server
")
}

Funcoes

PT

`serve_once` atende uma requisicao; `serve_forever` mantem o processo ativo; helpers HTML definem content-type.

EN

`serve_once` handles one request; `serve_forever` keeps the process alive; HTML helpers set the content type.
