    x11win

    namespace x11win15 funciones públicas13%ofs/stdlib/x11win.ofs

    OFS Standard Library — X11 Window Module Janela nativa X11 escrita 100% em OFS (Xlib via extern), sem runtime C. Apresenta um Canvas na tela e entrega eventos de teclado (com texto UTF-8 e acentos por tecla morta), mouse, roda, redimensionamento e fechamento.

    x11win.open("Meu App", 1280, 800)
while (x11win.is_open()) {
    forge ev = x11win.poll()
    while (ev != 0) { ... ev = x11win.poll() }
    x11win.present(cv)
    x11win.sleep_ms(8)
}
