    avi

    namespace avi17 funciones públicas17%ofs/stdlib/avi.ofs

    OFS Standard Library — avi: leitor AVI (RIFF/OpenDML) e decodificador Microsoft Video 1 (CRAM/MSVC, 16 bits) em OFS puro.

    forge v = avi.open("/.../op.avi")          // -1 se nao abrir
avi.codec(v)          // FourCC do video, ex.: "CRAM", "XVID"
avi.supported(v)      // true se o codec puder ser decodificado aqui
avi.width(v) / avi.height(v) / avi.frames(v) / avi.us_per_frame(v)
forge dst = ofs_alloc(avi.width(v) * avi.height(v) * 8)
avi.decode(v, i, dst) // quadro i em dst: 0xRRGGBB por pixel (stone)
avi.audio_format(v) / audio_channels / audio_rate / audio_bits
forge pcm = avi.read_audio(v)   // PCM do audio (formato 1), ou 0
avi.audio_bytes(v)              // tamanho de `pcm` em bytes
avi.close(v)

    O decodificador e sequencial: quadros delta dependem do anterior, entao decode(v, i) decodifica os quadros que faltam entre o ultimo e i (voltar no tempo recomeca do quadro 0). O arquivo fica aberto e cada quadro e lido do disco na hora (videos de 100 MB nao vao para a memoria).
