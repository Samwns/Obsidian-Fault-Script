    #default_is_literal

    typeck
    vein default_is_literal(d: stone) -> bool

    tipos dos parametros de uma vein/extern, separados por ',' Parametro com valor padrao (onda 4): b: stone = 3. O padrao e um literal (numero, texto, bool, null, ou -numero) e os parametros com padrao ficam no fim; a chamada que omite os ultimos argumentos ganha uma copia do literal (fill_defaults), entao o nativo e o interpretador veem a chamada completa. A Fault Refract usa isso para aceitar um parametro novo numa vein em uso (as chamadas antigas recebem o padrao).
