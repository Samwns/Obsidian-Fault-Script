    sediment

    namespace sediment41 funciones públicas19%ofs/ofscc/sediment.ofs

    OFS Compiler — Sedimento: arena do bedrock { } (A5.3) e aviso de vazamento simples. Roda depois do typeck (usa os tipos), nos dois modos, na mesma arvore para o llvmgen e o interpretador (e na Fault Refract).

    Arena (regra decidida em A5.3):

    - um bloco `bedrock { ... }` (tambem `tectonic bedrock`, `bedrock vein`)
  que aloca e uma arena: o que o PROPRIO codigo do bloco aloca
  (concatenacao, conversao para texto, `[...]`, `forge m: Monolith`,
  ofs_alloc/ofs_realloc, builtins de texto e de Array) vem de uma
  regiao liberada de uma vez na saida do bloco, em qualquer saida
  (return, shatter/erode, `?`). A arena e lexica: uma vein chamada de
  dentro aloca no heap normal (o llvmgen zera a arena ativa durante a
  chamada). O bloco que nao aloca nada continua so um bloco de baixo
  nivel (F4), sem arena (mesmo IR de antes). Marca: type_str "arena"
  no NK_BLOCK.
- escape: um valor que pode estar na arena e vai para fora dela
  (return, atribuicao a variavel/global/parametro de fora, campo ou
  elemento de objeto de fora, push/set em Array de fora, argumento que
  a vein chamada guarda, valor de vein/C desconhecido) e:
    obsidian: copiado para o heap (__bedrock_lift(v) -> ofs_arena_lift,
      que so copia se o texto estiver mesmo numa arena viva);
    Array, monolith, ponteiro, geode: [ERRO DE ARENA] em compilacao
      (dentro de `abyss { }` vale: o programador assume o risco).
  Funcoes C (`extern`/`rift`) nao guardam ponteiros (convencao do C);
  as do runtime que guardam (titulo da janela) contam como quem guarda.
- nivel de um valor: 0 = heap/fora; d = arena do bedrock de
  profundidade d. Variavel: nivel "de casa" = profundidade onde foi
  declarada; conteudo = maior nivel ja atribuido (ponto fixo por
  passadas). Parametro guardado: mascara por vein (ponto fixo entre as
  veins, pessimista com recursao).

    Vazamento: forge p = ofs_alloc(n) (ou malloc/calloc/realloc/ ofs_realloc) fora de arena que nunca chega a um seal/anchor, ofs_free, chamada (dono), return, atribuicao, campo, array ou geode gera [AVISO DE VAZAMENTO] no stderr (OFS_LEAK_WARN=0 silencia).
