    icons

    namespace icons3 funciones públicas100%ofs/stdlib/icons.ofs

    OFS Standard Library — Icons Module Icones vetoriais de interface (grade 24x24, traco arredondado), 100% OFS. Cada primitiva e rasterizada com antialiasing e unida por cobertura maxima, entao juncoes de tracos ficam limpas. Mascaras ficam em cache por (icone, tamanho) e podem ser desenhadas em qualquer cor.

    icons.draw(cv, icons.BACK, x, y, 20, 13421772)
