    raster

    namespace raster22 funciones públicas36%ofs/stdlib/raster.ofs

    OFS Standard Library — Raster Module Rasterizador vetorial com antialiasing, escrito 100% em OFS.

    Algoritmo: acumulacao de area assinalada por scanline (estilo font-rs). Cada segmento de reta deposita, em um buffer de acumulacao, a area que cobre em cada celula; a soma prefixada de cada linha resulta na cobertura exata (0..1) de cada pixel. Curvas quadraticas e cubicas sao achatadas em retas. Formas sobrepostas com a mesma orientacao se unem (cobertura e limitada a 1), o que permite tracos (strokes) montados por capsulas.

    Uso tipico:

    raster.begin(x, y, w, h)          // area da mascara em coordenadas do canvas
raster.move_to(...) / line_to / quad_to / cubic_to / close()
raster.fill(cv, cor)              // compoe a mascara no canvas e limpa

    Coordenadas sao crystal em pixels do canvas. Cor no formato do canvas: 0xRRGGBB opaco, ou argb(a, r, g, b) com alfa no byte alto.
