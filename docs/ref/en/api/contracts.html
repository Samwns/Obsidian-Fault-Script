    OFS Compiler — Contratos e minerais (A5.1)

    mineral UserId = stone grain value > 0           tipo com regra
mineral Email = obsidian grain contains("@")     (forma curta: value entra
                                                  como 1o argumento)
vein dividir(a: stone, b: stone) -> stone
    bearing b != 0                               pre-condicao
    settle result * b == a                       pos-condicao
{ ... }

    Roda depois do parser e antes do typeck, nos dois modos (mesma arvore para o llvmgen e o interpretador):

    1. registra os `mineral` e tira as declaracoes da arvore;
2. checagem estatica: com literais/constantes, uma regra que da falso
   com certeza e [ERRO DE CONTRATO arquivo:linha:col];
3. checagem em tempo de execucao (padrao; OFS_CONTRACTS=0 ou
   `ofs build --release` desliga): insere `if (!(regra)) falha` na
   entrada da vein (bearing e parametros de mineral), depois de cada
   `forge`/atribuicao de mineral e em cada `return` (settle e retorno
   de mineral). A falha chama __ofs_contract_fail(msg): "ofs: " + msg
   no stderr e codigo de saida 1, igual nos dois modos;
4. apaga os minerais: todo tipo `UserId` vira o base (`stone`), entao o
   typeck, o llvmgen e o interpretador nao mudam (base -> mineral checa
   a regra; mineral -> base e livre).

    ofs assay (assay_source): gera um core main que chama cada vein com bearing simples sobre inteiros nos limites (fronteira e +-1).
