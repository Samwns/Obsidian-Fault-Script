    stdlib

    magma

    namespace magmaclaim rift, abyss, magma7 public functions100%ofs/stdlib/magma.ofs

    OFS Standard Library — magma: compilar e carregar OFS com o programa rodando (Ideia 5, magma.cast). Plugins e mods escritos em OFS.

    attach {magma}
claim magma                                  // no topo de quem chama magma.cast

    forge m = magma.cast("mods/dobro.ofs")       // caminho, ou o proprio fonte (texto com \n)
if (!magma.cooled(m)) { echo(magma.crack(m)) }       // erro do compilador, sem derrubar o programa
forge dobro: vein(stone) -> stone = magma.vent(m, "dobro")
if (dobro != null) { echo(dobro(21)) }        // assinatura errada/sem a vein: null + magma.crack(m)
magma.release(m)                              // nao entrega mais veins (o codigo fica carregado)
magma.caprock("crust")                        // teto dos proximos mods ("" = sem teto)

    Como funciona (igual no ofs run e no binario do ofs build): o mod e compilado pelo ofscc num processo a parte (OFSCC_MODE=cast: IR + manifesto das veins com a assinatura canonica da F6), vira .so com o clang (-shared -fPIC -O2 -Wl,-Bsymbolic) num cache por hash do IR gerado (o fonte expandido com os attach, o clang e o sistema), e e aberto com dlopen (RTLD_LOCAL). O mod usa o runtime do programa que o carrega (mesmo heap, stdout e strings): no ofs run o ofscc ja e ligado com -rdynamic; o ofs build liga com --export-dynamic quem usa magma.cast. Compilador: OFS_MAGMA_OFSCC, o proprio ofscc (no ofs run), $OFSCC, o ofscc ao lado do ofs do PATH, ~/.local/lib/ofs, ofscc do PATH, /usr/local/bin, /usr/lib/ofs. clang: OFS_MAGMA_CC (ou OFS_QUARTZ_CC). Cache: OFS_MAGMA_CACHE, $XDG_CACHE_HOME/ofs/magma ou ~/.cache/ofs/magma. Ver docs/STANDARD_LIBRARY.md (magma) e docs/COMPILER_ARCHITECTURE.md.
