    OFS stdlib — geophone: agente da Fault Refract L3 no app Android

    Nao se anexa a mao: o ofscc o anexa so no build com celulas (ofs build --target android --refract, OFSCC_REFRACT=cells). O build normal e o de release nao o tem (nem as celulas).

    Escuta num socket Unix abstrato ofs-refract.<pacote>, que de fora do aparelho so o adb alcanca (adb forward tcp:P localabstract:...), e so aceita conexao do uid do adb (shell, 2000), do root ou do proprio app (SO_PEERCRED). Tudo roda na thread principal: o socket entra no looper dela (ALooper_addFd, como a entrada do android.ofs), entao o remendo e aplicado entre dois eventos e o runtime magma (que nao e thread-safe) nao ve outra thread.

    Protocolo v1, linhas de texto terminadas em '\n':

    app -> PC ao conectar: OFS-REFRACT 1 <pacote> <pid> <geracao>
PC -> app: MANIFEST              app -> PC: o manifesto (linhas) e END
PC -> app: PATCH <geracao> <n>   seguido de n bytes do .so
           app -> PC: OK <geracao> <ms> <veins> | ERR <geracao> <motivo>
PC -> app: PING -> PONG          BYE -> fecha a conexao

    O .so vai para code_cache/ofs-refract/, abre com dlopen e __ofs_refract_install grava nas celulas o endereco das veins novas.
