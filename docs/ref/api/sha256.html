    sha256

    namespace sha2566 funções públicas16%ofs/stdlib/sha256.ofs

    OFS Standard Library — sha256 (e crc32), 100% OFS

    attach {F:sha256.ofs}
forge h = sha256.file("/caminho/arquivo.bin")    // 64 hex minusculos, "" se nao abrir
forge h2 = sha256.bytes(ptr, n)                    // ptr = endereco (stone) de n bytes
forge c = sha256.crc32_update(0, ptr, n)           // CRC-32 (zip); encadeie passando o anterior

    Aritmetica de 32 bits em stone (64 bits) com mascara; le arquivos em blocos de 64 KB (nao carrega o arquivo inteiro).
