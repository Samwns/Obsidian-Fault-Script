    ofsdoc

    4 funções públicas50%ofs/tools/ofsdoc.ofs

    ofsdoc: auto-documentacao do OFS gerada a partir do codigo-fonte (ofs doc).

    Usado pelo wrapper ofs doc (compilado e guardado em cache). Variaveis de ambiente (o wrapper traduz os argumentos):

    OFSDOC_INPUT   arquivos/pastas .ofs separados por ':'
OFSDOC_OUT     pasta de saida (HTML + search.json)
OFSDOC_DOCS    pasta dos .md do projeto (veja tambem / funcoes inexistentes); "" desliga
OFSDOC_CHECK=1 so verifica (relatorio no terminal; exit 1 se houver funcao citada inexistente)
OFSDOC_DUMP=1  imprime o que foi extraido (usado pelos testes)
OFSDOC_ASSETS  pasta com ofsdoc.css e ofsdoc.js
OFSDOC_TITLE, OFSDOC_REPO (URL do GitHub), OFSDOC_ROOT (prefixo removido dos caminhos), OFSDOC_LANG

    Documentacao: docs/TOOLS.md.
