    #coerce_value

    typeck
    vein coerce_value(child_id: stone, to_t: obsidian) -> stone

    Valor child_id guardado num lugar do tipo to_t (forge com tipo, =, argumento, return, elemento de array): devolve o no a usar.

    inteiro -> crystal; crystal -> inteiro (trunca, como `as`);
bool -> inteiro (0/1); crystal/bool/variante -> obsidian (texto).

    Inteiro -> inteiro de outra largura fica com o back-end (trunca/ estende no store, igual nos dois modos).

    Parâmetros

    child_idstone
    to_tobsidian

    Retorno

    stone
