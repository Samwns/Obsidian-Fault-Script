    OFS Standard Library — audio_android: saida de som com AAudio (Android 8+)

    attach {F:audio_android.ofs}
audio.open()                          // 44100 Hz, estereo, i16
forge s = wav.load("/.../musica.wav")
audio.play(audio.CH_MUSIC, s, true)   // canal, som (wav.*), em loop
audio.set_volume(audio.CH_MUSIC, 80)  // 0-100
audio.stop(audio.CH_MUSIC)
audio.position(audio.CH_MUSIC)        // quadros ja tocados (relogio)
audio.pump()                          // 1x por quadro: libera sons trocados
audio.pause() / audio.resume() / audio.close()

    O mixer roda na thread de audio do AAudio (callback). Essa thread so le e escreve memoria crua alocada aqui (bloco de controle + PCM): nada de Array, string ou alocacao, porque o runtime do OFS nao e thread-safe. A thread principal so muda campos de 64 bits (atomicos no aarch64) e nunca libera um PCM que o callback ainda pode estar lendo: wav.free fica adiado ate o callback passar por pelo menos dois ciclos (audio.pump). Linkar com -laaudio (ofs build --target android ja faz).
