    quarry_json

    58 funções públicas34%ofs/tools/quarry_json.ofs

    quarry_json: texto, arquivos, versoes (semver) e JSON para o ofs quarry.

    Parte 1 da ferramenta ofs/tools/quarry.ofs (o gerenciador de pacotes). Tudo aqui e generico: nao sabe nada de registro, manifesto ou lock.

    JSON: arvore em arrays paralelos (qj_kind, qj_val, qj_key, filhos ligados por qj_first/qj_next). Strings guardam o texto JSON *com* os escapes (qj_str decodifica os comuns); qj_dump reescreve sem perder nada.
