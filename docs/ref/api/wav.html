    namespace wav8 funções públicas12%ofs/stdlib/wav.ofs

    OFS Standard Library — wav: decodificador WAV (RIFF) em OFS puro

    forge s = wav.load("/caminho/som.wav")          // -1 se falhar
forge s2 = wav.decode(ptr, len)                  // de um bloco na memoria
forge s3 = wav.from_pcm(pcm, quadros, canais, hz) // PCM i16 ja decodificado
wav.pcm(s)      // ponteiro para amostras i16 little-endian intercaladas
wav.frames(s)   // quadros (amostras por canal)
wav.channels(s) // 1 ou 2
wav.rate(s)     // Hz
wav.free(s)

    Formatos: PCM 8/16 bits (formato 1) e Microsoft ADPCM (formato 2, usado por muitos jogos de PC dos anos 90). Sem dependencias de plataforma: a saida de som fica em audio_android.ofs (AAudio).
