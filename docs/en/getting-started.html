Getting started

From installation to the first executable and web page in OFS.

Installation

Get the package for your system from the downloads page and use the `ofs` command.

Open downloadsCLI commands

First executable

Create `app.ofs`, verify it with `check`, run it with `run`, and build a native binary with `build`.

terminal
ofs check app.ofs
ofs run app.ofs
ofs build app.ofs -o app
./app

First web document

Write an OFS program that uses `attach {odl}` and `attach {oes}` to build documents and styles, then compile and run it to emit HTML and CSS ready for static hosting.
