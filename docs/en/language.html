What OFS is

EN

OFS is a self-hosted compiled language. The compiler is written in OFS, emits LLVM IR, and links against a native runtime.

Syntax

EN

Programs use `vein` functions, `forge` bindings, explicit returns, and `core main()` as the entry point.

hello.ofs
vein add(a: stone, b: stone) -> stone {
    return a + b
}

core main() {
    forge result: stone = add(20, 2)
    echo(result)
}

Types

EN

The base types include `stone`, `crystal`, `obsidian`, `bool`, integer widths, arrays, and `monolith` structures.

stonecrystalobsidianboolarraysmonolith

Modules

EN

Libraries are attached with `attach`, keeping native code, standard library modules, and web DSLs in the same model.

attach {math}

Import a standard library module.

attach {F:path/file.ofs}

Import a local OFS file explicitly.

extern vein

Declare runtime or C symbols.

core main()

Define the native entry point.

Low-level modes

EN

Blocks such as fracture, abyss, fractal, and bedrock are experimental tools for controlled runtime-level work.

Use these modes only when normal language semantics are not enough.
