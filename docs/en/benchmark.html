Test methodology

The `bash bench/run.sh` script compiles each implementation (OFS with the repository compiler and runtime, C with `clang -O2`, Rust with `rustc -O`), runs real processes, compares the output with `bench/expected/`, and keeps the median wall time. Each process runs with a memory limit (`ulimit -v`) and a time limit.

Measured programs

Six small, equivalent programs in every language, each exercising a different part of the runtime.

ProgramWhat it measures
emptyStartup: the program only prints ok. Also gives the empty binary size.

stringsBuilding and reading 1 MB of text.
sortQuicksort of 100 thousand integers in an array (a[i] = v).
alloc1 million small allocations.
RSSPeak resident memory of each program (/usr/bin/time -v).

How to read the data

Results depend on hardware, operating system, and build settings. Individual measurements reflect the tested workload, not universal speed claims.

memory: the process exceeded the memory limit and was terminated. timeout: it exceeded the time limit. failure: it exited with an error for another reason. The machine, date, and versions appear above the charts.
