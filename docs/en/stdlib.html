Core modules

These modules support small programs, examples, and compiler tools.

math

Numeric helpers.

string

Web modules

EN

The web layer ships as standard library, not as a separate external framework.

odl

Build browser documents from OFS.

oes

Generate style, responsiveness, and motion.

webui

Components and page server.

webserver

Native HTTP server.
