# OFS Documentation

This directory groups the English-facing technical documentation for Obsidian Fault Script.

- Start with [Getting Started](../GETTING_STARTED.md).
- Read the [Language Reference](../LANGUAGE_REFERENCE.md) for syntax, types, modules, and low-level modes.
- Use [ODL Reference](../ODL_REFERENCE.md) and [OES Reference](../OES_REFERENCE.md) for the native web languages.
- Use [Web UI](../WEB_UI.md) for the OFS web stack, Go Live, static hosting, and browser interoperability.
- Use [Compiler Architecture](../COMPILER_ARCHITECTURE.md) for the self-hosted compiler and LLVM pipeline.

The official site in `docs/*.html` is generated from OFS source in `src/site/src/`.
