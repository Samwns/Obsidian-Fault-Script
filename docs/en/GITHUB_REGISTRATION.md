# GitHub Recognition

## Repository Recognition

This repository uses `.gitattributes` so GitHub treats `.ofs` files as OFS:

```gitattributes
*.ofs linguist-language=OFS
*.ofs linguist-detectable=true
*.odl linguist-language=ODL
*.odl linguist-detectable=true
*.oes linguist-language=OES
*.oes linguist-detectable=true
```

This override applies immediately to repositories that include it.

## Syntax Grammar

The TextMate grammar lives in:

- `src/grammar/syntaxes/ofs.tmLanguage.json`
- `src/vscode-extension/syntaxes/ofs.tmLanguage.json`

Its scope is `source.ofs`, and the grammar is MIT licensed.

## Global GitHub Linguist Registration

GitHub Linguist requires a new language contribution to include:

1. A `languages.yml` entry without a manually invented `language_id`.
2. A separately maintained, acceptably licensed TextMate grammar.
3. Representative real-world samples, not tutorial hello-world files.
4. An ID generated by Linguist's `script/update-ids`.
5. GitHub code-search evidence of usage in the wild.

As of June 14, 2026, Linguist requires at least 2,000 `.ofs` files indexed in
the previous year, excluding forks, with reasonable distribution across public
repositories and users. Very new or hobby languages below that threshold are
explicitly not accepted.

A GitHub code-search check on June 14, 2026 returned 364 indexed `.ofs` files
in total and 133 after excluding `user:Samwns`. This is useful progress, but it
is below Linguist's acceptance gate.

The prepared metadata, samples plan, grammar URL, and acceptance gate are
documented in `docs/linguist-pr.md`.
