OAL — Obsidian Android Language

Um arquivo `.oal` descreve manifesto, telas de toque, estilos, ações e ciclo de vida; a lógica fica em `.ofs` (importada com `use` ou `attach`). O `oalc` gera `AndroidManifest.xml` e o código OFS das telas.

app.oal
use "biblioteca.ofs"

app "M.O.O.N" "com.fixedseat.moon"
  version "0.1.0"
  permission internet

style button.primario
  fill #8b6cff
  ink #101020
  curve 24
  pressed fill #5f45c8

screen biblioteca
  bar "M.O.O.N"
    button.icon "plugins" -> abrir_plugins
  button.primario "Importar jogo" icon=import -> importar
  list jogos from biblioteca.jogos
    item title=item.nome sub=item.motor -> abrir_jogo(item)
    empty "Nenhum jogo ainda."

on back -> voltar

Gerar o APK

A CLI compila para aarch64 com o clang do NDK, linka uma `.so` sem nenhum arquivo C e empacota com aapt2, zipalign e apksigner. Requisitos e limites em docs/ANDROID.md.

terminal
ofs build --target android app.oal -o app.apk
ofs build --target android app.oal --install --serial 
ofs build --target android jogo.ofs --manifest AndroidManifest.xml

Runtime

Tudo roda na thread principal do Android: callbacks do NativeActivity ligados com `fault_addr`, entrada pelo looper, frames pelo AChoreographer e desenho em software (canvas, raster, ttf, icons) sobre o núcleo de layout do OLL.

Recursos do v0

Referência completa em docs/OAL_REFERENCE.md.

app

Manifesto: nome, pacote, versão, ícone, orientação, permissões, tela cheia.

screen

bar, button, button.icon, title, text, list, grid, card, row, portrait, landscape.

fab, dpad

Camada flutuante com opacidade: botões flutuantes e D-pad virtual.

style

fill, ink, curve, opacity e estado pressed: o papel do CSS/OES no Android.

on

back, pause, resume, rotate, low_memory despachados para funções .ofs.

android.ofs

NativeActivity em OFS puro: fault_addr, ALooper, AChoreographer, ANativeWindow, JNI.
