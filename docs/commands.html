Comandos nativos

PT

Use check, run, build, ir e asm no ciclo diario da linguagem.

commands
ofs/dist/ofs check app.ofs
ofs/dist/ofs run app.ofs
ofs/dist/ofs build app.ofs -o app
ofs/dist/ofs odl page.odl -o index.html
ofs/dist/ofs oes theme.oes -o theme.css
ofs/dist/ofs translate legacy.html --to odl
ofs/dist/ofs translate legacy.css --to oes

Comandos web

PT

`odl` e `oes` geram artefatos de navegador a partir das linguagens web da OFS.

ComandoFinalidade
checkValida sintaxe e semantica.
runCompila e executa.
buildGera executavel nativo.
irMostra LLVM IR.
asmGera assembly.
odlCompila .odl para HTML.
oesCompila .oes para CSS.
translateTraduz HTML/CSS para ODL/OES quando possivel.

Tradutor

PT

O tradutor ajuda a trazer HTML/CSS legado para ODL/OES sem impedir hospedagem padrao.

O tradutor e util para migracao, mas o codigo final deve ser revisado como qualquer conversao.
Gerado por ODL e OES em OFS.
