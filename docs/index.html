O que e a OFS

Uma linguagem para aprender, compilar e descer perto do sistema quando precisar.

Self-hosted

Lexer, parser, type checker e geracao LLVM vivem no compilador OFS.

Nativa

A saida e LLVM IR linkada com libofs_runtime.a para gerar executaveis.

Hibrida

Console, canvas/window nativo e sites via webserver/webui no mesmo ecossistema.

Web UI oficial

Arquivos web sao explicitos: a extensao so usa Go Live quando encontra attach {webui} ou chamadas web.

webui_site.ofs
attach {webui}

core main() {
    forge body = webui.nav("OFS Web", webui.button("Docs", "#docs"))
    body = body + webui.grid(
        webui.card("Nativa", "LLVM + runtime")
        + webui.card("Web", "HTML e estilo gerados pela stdlib")
    )

    webui.serve(8080, "OFS Web", body)
}
