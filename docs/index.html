Stack Magma: Runtime Puro em OFS

Adeus às dependências externas em C. Todos os subsistemas são escritos na própria linguagem.

Magma

Ponto de entrada do runtime, bootloader e inicialização de tabelas de símbolos.

Reservoir

Alocação dinâmica determinística, liberação e gerenciamento direto de blocos de memória.

Facet

Manipulação de strings, concatenação, fatiamento, substring e conversões textuais.

Matrix

Coleções dinâmicas, arrays com redimensionamento, filas e pilhas estruturadas.

Outlet

Entrada e saída padrão, streaming de texto e escrita rápida em arquivos.

Foundation

Acesso ao sistema operacional, variáveis de ambiente, processos filhos e caminhos.

Pulse

Temporizadores de alta precisão, medição de ciclos e controle temporal em milissegundos.

Frame & Impulse

Gerenciamento de janelas gráficas, telas virtuais e captura de eventos de mouse e teclado.

Compilação Nativa & Pipeline LLVM IR

Zero Clang, zero dependências legadas em C e determinismo byte-a-byte

1. Fonte OFS programa.ofs
→
2. Frontend ofscc Lexer + Parser + Tipos
→
3. Backend llvmgen Emissão LLVM IR SSA
→
4. Assembler llc Geração de objeto (.o)
→
5. Linker + Magma ld / ld.lld + magma.o
→
6. Binário Nativo ELF (Linux) / PE (Win)

⚡ Zero Dependência de Clang

O compilador utiliza o llc diretamente para gerar arquivos de objeto de máquina e os ligadores nativos do sistema operacional (ld no Linux, ld.lld no Windows), eliminando centenas de megabytes de dependências externas.

🔒 Determinismo Total

Compilações sucessivas produzem exatamente o mesmo código LLVM IR (validado via cmp -s v3.ll v4.ll). O resultado da compilação é matematicamente previsível e reproduzível em qualquer ambiente.

🪟 Cross-Compilação Windows

Gere executáveis Win32 nativos PE32+ diretamente do Linux com a flag --target windows. As chamadas à API Win32 funcionam de forma nativa e podem ser testadas no Wine.

🚀 Performance de Compilação

O pipeline completo atinge tempos de compilação entre 50ms e 100ms para programas típicos, permitindo ciclos de desenvolvimento instantâneos sem atrasos de transpiladores lentos.

Terminal — Comandos do Compilador OFS
# Compilar para binário nativo otimizado
$ ofs build app.ofs -o app
[OFS] Compilando app.ofs via llvmgen e llc nativo...
[OFS] Linkando com Stack Magma (magma.o)...
[SUCCESS] Binário gerado: ./app

# Execução direta e instantânea
$ ofs run app.ofs

# Emissão de LLVM IR intermediário para inspeção
$ ofs ir app.ofs -o app.ll

# Cross-compilar para Windows (PE32+ .exe)
$ ofs build app.ofs --target windows -o app.exe

OLL — Obsidian Layout Language

Interfaces nativas declarativas, ricas e desacopladas da lógica de programação

🎨 Totalmente Declarativo

Descreva hierarquias de janelas, colunas, cartões, abas, botões e barras de progresso sem acoplar estado à renderização.

🪟 Janelas Nativas a 60 FPS

Suporte a renderização acelerada de janelas nativas no Linux e Windows com loop de eventos responsivo, hover e clique.

📐 Flexbox & Box Model

Cálculo automático de dimensões, margins, paddings, gaps, alinhamento e dimensões dinâmicas.
