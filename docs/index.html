OFS: linguagem compilada, runtime nativo e DSLs web proprias.

Obsidian Fault Script usa um compilador self-hosted, gera LLVM IR, linka uma runtime nativa e inclui ODL/OES como linguagens fonte para sites.

ComecarDownloadsGitHub
exemplo.ofs
attach {odl}
attach {oes}

vein page() -> obsidian {
    forge head = odl.css("site.css")
    forge body = odl.h1("OFS Web")
    return odl.document("pt", "OFS", "site oficial", head, body)
}

Componentes tecnicos

O ecossistema separa compilador, runtime, biblioteca padrao, ferramentas web e empacotamento.

Self-hosted

Lexer, parser, type checker e geracao LLVM vivem no compilador OFS.

Nativa

A saida e LLVM IR linkada com libofs_runtime.a para gerar executaveis.

Hibrida

Console, canvas/window nativo e sites via webserver/webui no mesmo ecossistema.

ODL + OES

ODL define documento; OES define efeitos, tokens, layout e movimento. Ambos sao fontes OFS, nao HTML/CSS renomeados.

site.ofs
attach {odl}
attach {oes}
attach {webserver}

core main() {
    forge head = odl.css("site.css")
    forge body = odl.main("app", odl.h1("OFS Web"))
    webserver.serve_html_forever(8080, odl.document("pt", "OFS", "site", head, body))
}
